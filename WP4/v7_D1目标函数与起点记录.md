# v7 D1 目标函数与起点

权威输入为14号包的`curve_roles_v7.csv`与`salt_transport_tidy.csv`；本轮目标只取Book1的B组六膜、每膜6个非零点，共36点。每膜用自己的t=0电导作基线，原单位`μS/cm`保持不变。预测在同一S系列、固定种子7001–7008的八个网络上先逐时求右池无量纲活度`u_R`的均值，再乘共同`Q`。残差为`asinh(y_pred/1)-asinh(y_obs/1)`；先对各膜6点均方，再对六膜平均，`L=Σ_hΣ_t r²/(6×6)`、`E=√L`。没有对负读数增量裁剪或把电导换算成绝对盐浓度。

优化坐标为N0的`(log10 α,log10 Q)`及NS额外共享的`β`；边界分别`[0,5]`、`[0,6]`、`[0,6]`。`v7_d1_starts.csv`保存每模型12个实际起点：首个为区间中点，其余11个各坐标按PCG64种子20261022分层置换。N0固定β=0；本阶段不做逐膜参数或ND。每起点同用SciPy `least_squares`的`trf`、两点差分、`ftol=xtol=gtol=1e-8`，实际残差函数调用（包括差分）最多200次；达到上限记`max_eval`，不称收敛。逐起点追加状态与最佳参数到`v7_d1_fit_fullB_runs.jsonl`。
