# 湿态 HA/A⁻ 启动门与停止规则

湿态不是干态结果的乘法修正。只有干态三组方向在当前精度下支持薄组更强，才启动薄/厚两组的水相 HA 与 A⁻ 计算。

## 启动门

1. 干态 `R_dry` 的区间整体高于 1；
2. 三个独立表面和时间块的收敛证据已记录；
3. 同一 PE 力场在干、湿之间保持不变；
4. 水模型、辛酸参数、A⁻ 净电荷、电中性处理、体相平台和标准态已写入输入；
5. 湿态只保留薄/厚两组，每组仍使用已建的三份独立微结构。

## 湿态目标

对 HA、A⁻ 分别得到水相到 PE 表面的自由能曲线和 `K_thin/K_thick`。在近中性水用有出处的体相 pKa 给出 `x_HA` 与 `x_A`，再计算：

```text
R_wet = (x_HA*K_thin,HA + x_A*K_thin,A) /
        (x_HA*K_thick,HA + x_A*K_thick,A)
```

## 停止规则

- 干态方向不成立：停止，不扩展探针或湿态矩阵；
- 湿态排序消失：结论停在“干态更易吸附”；
- 误差区间同时包含 1 和 1.84：写“当前计算分辨不开”；
- 不能把干态比与湿态比相乘，也不能把 ζ 反演位点密度当作湿态覆盖度。
