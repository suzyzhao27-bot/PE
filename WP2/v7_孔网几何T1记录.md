# v7 T1：冻结孔网几何与连通预算

入口：`src/effective_network_model/v7_network_geometry.py`。实际命令：

```powershell
.\.venv\Scripts\python.exe src\effective_network_model\v7_network_geometry.py
```

采用14号任务包`configs/frozen_spec.json`：H固定draw357结构；S按四个锚点在ln h上线性插值、范围外保持最近端点。六厚度65/120/200/350/700/2600 nm、H/S、种子7001–7008，共96个网络。每个网络6×6周期横向、`n_z=ceil(h/s)`，水相代理`ε=φ_A`。孔体半径采用截断对数正态且求底层均值以匹配截断后理论均值；孔体随机数与轴向边随机数由不同PCG64子流生成。对同种子不同h，预生成最大40层，再截取前`n_z`层。节点、内部横向/轴向边与双面端口均保存，不筛选贯通网络。

结果：`WP2/v7_network_geometry_audit.csv`逐网络记录形貌输入、格距、层数、节点和边数、实际半径样本均值、体积相对误差、两面端口面积占预算、面积截断边数、贯通/单侧/孤立节点数以及配置和几何身份；`WP2/v7_network_tables.jsonl.gz`保存96个网络的节点/边表。CSV的`geometry_hash`按对应网络规范序列化文本计算，供N0/NS在同一几何上复用，不是材料原始数据的额外哈希。

本机运行退出码0。96网的最大`|ΣV−εAh|/(εAh)=1.82×10⁻¹⁶`，低于T1的`10⁻¹²`；无重复边，全部边长度/半径/面积为正，两面端口面积占预算最大分别0.34399/0.37388。节点数36–1440、边数144–3889。逐条重读压缩表，96个几何身份全部匹配CSV；压缩表约2.11 MB。主`p_z=0.65`这96个网络中单侧和孤立节点均为0，面积截断边也为0，均按实际值保留，不能伪称出现断网。

为核对组件登记分支，临时在内存中将`p_z=0`（仅技术退化例，不改冻结配置），350 nm H、seed7001得到6层216节点：贯通0、单侧72、孤立144；所有节点都被分类。该例不属于主物理矩阵，也不替代规定的敏感性计算。

**技术边界：** T1几何预算与连通登记通过；仍需把同一网络与N0/NS输运求解器连接。现有节点/边表尚未赋模型相关K与g，因为β可变，不能把β=0的导通误用到NS。T2–T8、实验比较、随机网络的P和盐容量均未运行；不要据T1认定模型物理机制或连续极限已证实。
