# v7 C1 不拟合物理矩阵

实际命令：

```powershell
.\.venv\Scripts\python.exe src\effective_network_model\v7_c1_main.py
.\.venv\Scripts\python.exe src\effective_network_model\v7_c1_summary.py
.\.venv\Scripts\python.exe src\effective_network_model\v7_c1_ablations.py
```

主矩阵为H/S×六厚度×β=0/1/3/6×种子7001–7008，共384行。每行用原冻结孔网计算固定池P、α=10³ m⁻¹且Q=1时120 min右池活度、`ΣV_iK_i`、两池贯通体积分数、外端口/内部边的稳态耗散份额。β只共同改变节点`K_i=exp(−βa_ref/r_i)`及边导通中的`exp(−βa_ref/a_e)`；所有模型输出未拟合实验。固定池把左/右活度分别设1/0，边耗散`g(Δu)²`的总和与左侧通量乘单位驱动相等。闭合两池的盐量为`Σ C0 V_iK_i u_i`，池节点K=1。

`v7_c1_main_matrix.csv`有384/384 PASS、0失败；最大闭合总盐相对误差`9.77×10⁻¹²`，最大稳态耗散账本相对误差`1.13×10⁻¹²`，最小活度0。所有主网贯通体积分数为1；这是冻结代理网络的实现结果，不是实物全部孔体都连通。`v7_c1_main_summary.csv`按每8个种子做48行集合统计，保留最小/最大范围，并给相邻厚度的P比、120 min右池活度比与有限区间`ΔlnP/Δlnh`。凡`nz`变化的区间已标记，不把斜率尖变解读为物理临界指数。

在β=3、α=10³ m⁻¹下的三项单因素消融共288/288 PASS、0失败，见`v7_c1_ablations.csv`；最大盐量误差`2.63×10⁻¹²`、耗散账本误差`2.76×10⁻¹³`、最小活度0。对96个同身份主网的β=3集合，取消外access、设q=1、设p_z=1的**集合均值P之比**分别为1.00356、24.45747、1.10657；这与逐网比值均值不同。q与p_z变体使用相同种子与冻结子流，仅改变规定单项。q=1有强几何情景效应，但不能据此认定真实PE喉道或机制。

一个直观例子：H主网的350/200 nm集合均值P比，在β=0为0.54374、β=3为0.50296；S主网对应为0.45932、0.12261。120 min右池活度还受有限池趋于平衡影响，不可当成稳态P的等价指标。C1完成不等于技术T6、实验D矩阵、C2尺寸/种子检验或C3轴对称PNP通过。
