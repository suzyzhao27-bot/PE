# v7 容量上界与闭合体系自由能定向检验

实际命令：

```powershell
.\.venv\Scripts\python.exe src\effective_network_model\v7_thermo_capacity.py
```

脚本读取冻结配置与T1的96个网络；对β=0/3输出`v7_geometry_capacity_bound.csv`的192行。`V_i=εs²Δz`、`K_i=exp(−βa_ref/r_i)≤1`，故总增量盐容量`ΣV_iK_i≤ΣV_i=εAh≤Ah`。这只是代理几何水相体积与有效盐分配上界，不是实测湿态孔体积。192行的`ΣV_iK_i/(Ah)`在β=0为0.286780–0.345000，β=3为0.008400–0.033306。α=1000 m⁻¹时另列容量/右池体积的条件值；未拿未知真实A、V_R代入。

闭合体系的无量纲活度`u_i`对应盐量`N_i=C0 M_i u_i`，其中`M_i=V_iK_i`，两池K=1。总盐因每条边的`g_ij(u_i−u_j)`在两端成对抵消而守恒。取`F/(RT C0)=Σ M_i u_i(ln u_i−1)`，零活度项按极限设为0；正活度时每条边耗散`−g_ij(u_i−u_j)ln(u_i/u_j)≤0`。该自由能只适用于闭合双池；固定池须计入外部化学功。

`v7_free_energy_checks.json`保存H/200 nm/seed7001、α=1000 m⁻¹、β=0/3及“主初态含零/全部正初态”四组，在0、0.001、0.01、0.1、1、10、60、120 min的归一化自由能、盐量误差和最小活度。归一化尺度是`max(|F_initial|, initial_total_salt)`，单位均按`F/(RT C0)`的体积量取。四组最大正向自由能步差`9.27×10⁻¹³`，低于T5的`10⁻¹⁰`门槛；没有裁剪浓度。该定向集合不能代替全参数和ND正式T5/T8。

历史v6 M2另存`v7_legacy_M2_capacity_bound.csv`：若旧χ解释为死端水，`γ=Aε/V_R`且`ε(1+χ)≤1`，则`V_R/A≤1/[γ(1+χ)]`。旧全数据和2600 nm留出参数分别要求`V_R/A≤7.699×10⁻¹¹ m`及`1.000×10⁻¹² m`，仅为历史模型的必要条件，不是本轮v7参数或实测池深。无入口、固定池、均匀场、快速交换的旧极限还给出`P t_lag=ε(1+χ)Kh/6≤h/6`；不能直接套到v7有限池或空间变场模型。
