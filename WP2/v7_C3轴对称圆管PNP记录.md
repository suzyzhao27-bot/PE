# v7 C3 轴对称圆管 PNP 局部参照

实际命令：

```powershell
.\.venv\Scripts\python.exe src\finite_pnp\v7_c3_main.py
.\.venv\Scripts\python.exe src\finite_pnp\v7_c3_compare.py
.\.venv\Scripts\python.exe src\finite_pnp\v7_c3_refinement.py
```

适配器`src/finite_pnp/v7_axisymmetric_pnp.py`仅求`0≤r≤a,0≤z≤10a`的水域。用环形有限体积的面积/距离权重解泊松式`−ε∇²φ=F(c_+−c_−)`；壁上`ε∂φ/∂n=σ`且两离子法向通量0，轴上对称，两端浓度/电势为定值。离子通量用Bernoulli稳定通量，未知量为`ln c_±`以保证正性；调右端电势令截面`F_+=F_-`。与旧方形纤维PNP共用的只是通量离散思想及Bernoulli函数，水域网格、权重、壁界与端口均为新实现；没有外水域或access。

按冻结`a=5/25/50 nm`、`c_R=1/100 mol/m³`、`σ=0/−0.1/−1 mC/m²`、`c_L/c_R=1.01/10`的36个工况在24×240格全部计算成功，见`v7_c3_transport.csv`；18组共同浓度平衡容量用±1%和±0.5%差分，全部成功，见`v7_c3_capacity.csv`。最大零电荷盐通量相对解析`D_bπa²(c_L−c_R)/L`误差`0.1783%`；36工况最大相对净电流`1.38×10⁻⁸`、单离子端点守恒误差`8.67×10⁻¹⁰`、最小浓度`0.2328 mol/m³`。18组差分步长的`K_inc`最大相对差`5.06×10⁻⁶`，`K_inc`范围`0.8166–1.0000`。共同浓度、非零壁电荷的一个代表例盐流率绝对值`2.03×10⁻³² mol/s`；此时以近零离子流作分母的相对电流无意义，不把它用于1e-6门槛。半幅小驱动`1.005`与`1.01`所得导通比为`0.99882`，仅作极限诊断。

`v7_c3_ns_comparison.csv`逐一列出四个预设β=0/1/3/6的无access圆管NS因子`K=exp(−βa_ref/a)`，并同时比较PNP小驱动盐导通对同尺度零电荷值的比和增量盐容量`K_inc`；没有给每个孔另拟合β。β=0在18组中有17组两量相对误差均≤20%，β=1/3/6均为0/18。最不利组是`a=5 nm,c_b=1 mol/m³,σ=−1 mC/m²`，四个固定β中最小联合相对误差仍为`44.13%`。该局部工况的标量闭合不受支持；β不能据此认证为实测PE表面电荷。`v7_c3_nearest_diagnostic.csv`只用于确定任务书所需的最不利网格点，不把逐点最近β作为材料参数。

四个`a=5/50 nm`、`c_b=1/100 mol/m³`、`σ=−1 mC/m²`大驱动工况和上述最不利点在48×480格复核，5个盐流率相对主格变化最大`5.25×10⁻⁵`；对应4组平衡容量变化最大`6.87×10⁻⁵`，见`v7_c3_refinement.csv`。全部低于1%，相对净电流最大`4.19×10⁻¹⁰`，故不触发96×960。此处只是固定电荷的圆管局部参照，不能说明实际PE有该σ或真实孔道为圆管，也不能替代步骤4六膜拟合。
