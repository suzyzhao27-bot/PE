# P2 开测前执行清单 v0

**日期：** 2026-10-16
**状态：** 操作草案；不代表阶段 2 已冻结或获准开测
**用途：** 将 B20、B21、B22 的记录、校验和计算入口按实际执行顺序集中列出。模板均为空表或显式 `unknown`，不包含虚构实验参数。

## 1. 样品与 O/S/W 分配

1. 在查看暴露后测量结果前，将液体/批次、暴露条件、测量协议、质量与长宽变化上限、视觉损伤规则和失败处置填入 `liquid_compatibility_threshold_template.csv` 的工作副本。
2. 将真实兼容性暴露记录填入 `liquid_compatibility_template.csv` 的工作副本，先分别校验判据与记录，再用 `evaluate_liquid_compatibility.py` 机械计算质量和长宽绝对变化率。人工填写的 `compatible` 不能覆盖预声明判据。
3. 将真实母膜、裁片、位置、用途、协议液体身份/批次、兼容性记录、裁片尺寸、仪器/夹具和处理条件填入 `src/data_ingest/osw_sample_registry_template.csv` 的工作副本。只有机械评估通过且液体身份/批次一致的兼容性记录 ID 才能被 ready 样品登记引用。
4. 每张母膜至少提供 3 个唯一裁片 ID。
5. 在查看任何测量结果前，使用研究者登记的随机种子调用 `osw_randomization.assign_treatments()`。
6. 将分配结果、种子、执行人和时间写回登记表。
7. 运行：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\validate_liquid_compatibility_thresholds.py <兼容性判据.csv>
.\.venv\Scripts\python.exe .\src\data_ingest\validate_liquid_compatibility.py <兼容性记录.csv>
.\.venv\Scripts\python.exe .\src\data_ingest\evaluate_liquid_compatibility.py <兼容性记录.csv> <兼容性判据.csv>
.\.venv\Scripts\python.exe .\src\data_ingest\validate_osw_protocol.py <填写后的样品登记表.csv>
```

`protocol_ready=true` 只表示结构完整。兼容液体、仪器、空白和签字仍须审查。

## 2. 电导校准

1. 将标准液身份、浓度、电导、温度、温度补偿和来源记录填入 `conductivity_calibration_template.csv` 的工作副本。
2. 同一 `calibration_id` 只能使用一致的单位、温度基准和温度补偿状态。
3. 至少两个单调校准点；正式实验应按实际范围增加校准点。
4. 运行：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\conductivity_calibration.py <填写后的校准表.csv>
```

区间外电导不外推，直接失败。

## 3. 空白与预声明阈值

1. 在 `blank_registry_template.csv` 的工作副本中登记无膜、不透膜、液体/容器和电极/盐桥空白。
2. 盐输运最低要求 ready 的无膜和不透膜空白；电位测量最低要求 ready 的电极/盐桥空白。
3. 根据仪器分辨率、校准残差和空白结果，在 `quality_threshold_template.csv` 的工作副本中预声明校准漂移、盐量闭合、无膜空白、不透膜空白和温度偏差阈值。
4. 阈值须在查看 O/S/W 差异前登记依据、处置、批准人和批准时间。
5. 运行：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\validate_blank_registry.py <填写后的空白表.csv>
.\.venv\Scripts\python.exe .\src\data_ingest\validate_quality_thresholds.py <填写后的阈值表.csv>
```

## 4. 盐输运运行日志

1. 复制 `salt_transport_run_template.csv`，逐时间点登记两侧电导、体积、取样、补液、补液浓度、温度、面积、blank、夹具和泄漏状态。
2. 每行固定为 `record_phase=pre_event`：先记取样前状态，再记本时点取样/补液。
3. 同一运行固定接收侧、样品、单位、校准、面积、blank 和夹具。
4. 运行结构校验：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\validate_salt_transport_runs.py <填写后的运行日志.csv>
```

5. 校验通过后，连接校准并计算浓度、盐量闭合和累计平均通量：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\process_salt_transport_runs.py <运行日志.csv> <校准表.csv> --output <结果.json>
```

输出为 SI 制盐量与通量，但不自动获得机制拟合资格。

## 5. 独立 Na/Cl 与湿态通路

1. 在 `independent_readout_template.csv` 的工作副本中登记独立 Na、独立 Cl、中性示踪及可选的对称电解质 G 方法，并明确取样体积预算、单位、稀释倍数、检出/定量限、校准上下限和预期信号范围。
2. 中性示踪必须记录电荷状态依据、回收、吸附和稳定性检查。
3. ready 方法必须满足取样体积不超预算、预期最低信号可定量且预期范围位于校准区间内；数值仍由实际仪器和空白试验提供。
4. 运行：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\validate_independent_readouts.py <填写后的独立读数表.csv>
```

## 6. 统一准入检查

当前空模板状态可运行：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\assess_project_readiness.py
```

实际开测前，向统一入口传入经过审查的工作副本：

```powershell
.\.venv\Scripts\python.exe .\src\data_ingest\assess_project_readiness.py `
  --salt-tracker <历史曲线记录.csv> `
  --compatibility-registry <兼容性记录.csv> `
  --compatibility-thresholds <兼容性判据.csv> `
  --osw-registry <样品登记.csv> `
  --calibration <校准表.csv> `
  --run-log <运行日志.csv> `
  --blank-registry <空白表.csv> `
  --threshold-registry <阈值表.csv> `
  --readout-registry <独立读数表.csv>
```

不传参数时，入口读取仓库中的空模板和历史曲线 tracker，只用于显示未闭合项。只有正式看板和签字协议可以授权开测、参数冻结或机制拟合。
