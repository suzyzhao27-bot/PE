# 200 nm 旧时间曲线的读数扰动门槛（导师接续任务二）

**研究问题：** 原始四个读数在“有限池、充分混合、固定体积、无取样/额外盐源、电导与浓度呈仿射关系”的条件下，不符合**瞬时有效传输系数 `k(t)≥0` 且只增不减**。若允许每个原始读数最多改变 `ε`，需要多大改动才能解除这个代数矛盾？`ε` 是人为稳健性预算，不是仪器误差或统计置信区间。

## 原始点与条件

只读取 `src/effective_network_model/core/inputs/Book1__Sheet1.csv` 的 Book1 C/E 列，200 nm 标签在 0、20、40、120 min 的电导数值为 `1.53、2.35、2.70、15.45`；C 时间列由原 Origin 图线绑定审计确认。端点增量为 `13.92`。E 列单位沿同表电导标签继承为 `μS/cm`，曲线级单位尚待实验记录确认，因此输出同时保留“原表电导单位”的写法。扰动直接加在四个原始读数 `κj` 上，之后**共同使用同一个改动后的 0 min 基线**做 `qj=κj−κ0`；120 min 分母也从改动后的同一列端点计算。

条件模型写作 `dq/dt=k(t)(Qeq−q)`，其中 `Qeq>q120` 是有限平衡增量。令 `X(t)=−ln(1−q(t)/Qeq)`，则 `dX/dt=k(t)`。`k(t)` 非负且非减意味着各时间窗的 `X` 平均斜率须非负且依次非减；前两个等长 20 min 窗首先要求 `X40≥2X20`。整理可得

`Qeq≤q20²/(2q20−q40)`（当 `2q20−q40>0`），同时必须 `Qeq>q120`。

对每个读数施加同一个最大幅度上限 `|δκj|≤ε`。在下述门槛以内，上式可行性余量 `F=q20²−q120(2q20−q40)` 对四个原始读数的单调方向确定：提高 `κ0`、降低 `κ20`、提高 `κ40`、降低 `κ120` 最有利。这给出**全扰动盒的解析上界**，不是随机找一组扰动。把 `(+ε,−ε,+ε,−ε)` 代入并求 `F=0`，得到最小可行扰动的**下确界**：

**`ε*=0.110972241` 原表电导单位，约为旧 120 min 增量 13.92 的 `0.797214%`。**

恰在 `ε*` 时只能取 `Qeq=q120`，使 `X120` 发散；严格有限的 `Qeq` 需要 `ε` **略大于**该值。程序构造 `ε=0.111072241` 的实际可行例子，使用共同基线重新计算，取 `Qeq=13.718256`，得到 0–20、20–40、40–120 min 的 `X` 平均斜率分别为 `0.002227960、0.002229331、0.080272213 min⁻¹`，均非负且非减。因此 `ε*` 是紧的下确界，非仅必要条件的粗下界。改动后的原始读数和精确结果见 `data/processed/v5_time_reading_perturbation.json`。

**科研读法：** 这个门槛相对于 13.92 总增量不足 1%，但相对于早期 0–20 min 的 0.82 增量并不小。由于没有该实验的真实仪器误差、空白、取样史或独立重复，不能说旧曲线已统计排除单调开启；应把原来的“精确点列条件反例”弱化为“对约 0.11 原表单位的有向读数改变敏感”。即便得到可靠误差，也只检验上述单状态有限池方程，不能据此排除所有膜内储盐、吸附、瞬态扩散或润湿机制。

**同预算下的补充交叉核查：** 将相同 `ε*` 作为每个原始读数的独立最大幅度预算，分别对 120 与 2600 nm 曲线在共同 20、40 min 计算“先改原始读数，再共用本列基线和端点”的归一化差值区间。20 min 的 `120−2600` 差始终在 `+0.140196…+0.171156`；40 min 始终在 `−0.162535…−0.131575`。因此这**一对**曲线的 20–40 min 高低次序交叉在该假设预算内仍存在。区间是对所有允许原始点扰动的保守覆盖，不把同一基线或分母拆成独立误差；没有证明全部 13/15 对交叉都稳健，也没有测得实际误差。

## 本机执行与验收

程序 `src/effective_network_model/time_reading_perturbation.py` 仅用 Python 标准库。实际运行：

```powershell
.\.venv\Scripts\python.exe -B .\src\effective_network_model\time_reading_perturbation.py --output .\data\processed\v5_time_reading_perturbation.json
```

本机退出码 0；核对源四点、C 列时间和端点增量、门槛方程残差 `<4×10⁻¹⁵`，并对有限 `Qeq` 的三段斜率逐项验算。120/2600 nm 的共同时间列、差值区间两端与符号亦定向核对。没有改动原始 Book1，也没有引入膜别延迟拟合。
