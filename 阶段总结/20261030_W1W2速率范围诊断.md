# W1/W2速率范围诊断

2026-10-30。读取25号本地包冻结的20号`interval_transport.csv`。对C1/C2两种旧浓度转换、B/R各三厚度，共12条**单曲线**记录比较W1（0–60 min）与W2（60–100 min）的区间等效速率。T80/T85的这两个汇总窗口原`λ`逐项相同，故不重复计成24条独立证据。逐行数值见`data/processed/salt_transport/25_W1W2速率区间诊断_20261030.csv`。

沿用20号ρ相对**操作性容差**，`ρ=1/λ`、`ρ∈[(1−δ)ρ_hat,(1+δ)ρ_hat]`。两窗口允许同一恒定区间等效ρ的最小容差为`δ_min=|λ_W2−λ_W1|/(λ_W2+λ_W1)`。这是区间交集的解析条件，不是测量置信区间，也没有把两个窗口当独立膜重复。

| 转换 | 曲线 | `λ_W2/λ_W1` | `δ_min` | δ=.20时交集 |
|---|---|---:|---:|---|
| C1 | B700 | 0.5813 | 0.2648 | 无 |
| C1 | R700 | 4.1609 | 0.6125 | 无 |
| C2 | B700 | 0.5820 | 0.2643 | 无 |
| C2 | R700 | 4.1608 | 0.6125 | 无 |

其余8行在δ=.20时有交集。B700的后窗速率低于前窗，R700相反且增幅更大；这说明**单一恒定区间等效率**不能同时落入这4行的两个ρ容差区间。浓度依赖的PB迁移、外阻分配或其他静态物理参数也可使两个窗口的等效率不同；本诊断不构成静态模型不相容证书，不推导必要时间变化，更不宣布真实进水或孔道打开。

`src/mechanism_w1w2_rate_diagnostics.py`运行退出码0，输出12行，其中4行不重叠；逐项要求源状态`VALID`、正λ、唯一身份和T80/T85窗口λ完全一致。λ单位`s⁻¹`，ρ单位`s`。没有新PB、时序积分、LP、拟合或实验。云端裁剪包的12条固定诊断明细不可读，本表是依据本地20号资料选取的12条候选诊断，**不能认证为云端正式子集**。
