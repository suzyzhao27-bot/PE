# P2/B21 空白、校准与质量闭合草案 v0

**日期：** 2026-10-16  
**状态：** 预备草案；不代表 B21 已完成或实验协议已冻结  
**用途：** 在仪器和历史记录尚未全部闭合时，先固定计算关系、最小记录和失败判据框架。允许暂用明确标注的 provisional 输入，不允许把估计值写成实测值。

## 1. 可接受的临时输入等级

| 等级 | 来源 | 当前允许用途 |
|---|---|---|
| measured | 仪器原始文件、实验本或可定位记录 | 正式质量闭合与后续分析候选 |
| reported | 论文、报告或设备说明书中的明确数值 | 范围核对；须保留来源 |
| provisional | 研究者暂定的装置或操作值 | 试算、模板演练和实验准备 |
| unknown | 尚无可靠信息 | 保持缺失；不得由模型反推 |

provisional 输入到位后可以运行计算链，但输出必须标记为 provisional，不能用于机制验证或参数冻结。

## 2. 电导校准

每个校准点至少记录：标准液身份、NaCl 浓度及定义、原始电导、温度、温度补偿状态、blank、仪器和校准时间。校准函数记为：

\[
C = f(\kappa, T)
\]

其中 \(\kappa\) 为原始电导，\(T\) 为测量温度。函数形式由实际校准点和适用区间决定，不预设线性。超出校准区间的数据不得外推后继续计算通量。

若暂时只有名义校准或设备默认温度补偿，可先标为 provisional，用于检查数量级；不得与正式校准结果混写。

## 3. 体积与盐量更新

对左右储液池分别记录每次取样前浓度 \(C_{s,k}^{-}\)、取样体积 \(q_{s,k}\)、补液体积 \(r_{s,k}\) 和补液浓度 \(C_{s,k}^{rep}\)，其中 \(s\in\{L,R\}\)。体积更新为：

\[
V_{s,k}^{+}=V_{s,k}^{-}-q_{s,k}+r_{s,k}
\]

累计盐量闭合使用：

\[
N_k=C_{L,k}V_{L,k}+C_{R,k}V_{R,k}
+\sum_{i\leq k,s}q_{s,i}C_{s,i}^{-}
-\sum_{i\leq k,s}r_{s,i}C_{s,i}^{rep}
\]

初始盐量为 \(N_0\)。闭合偏差为：

\[
\varepsilon_N=\frac{N_k-N_0}{N_0}
\]

若存在蒸发、泄漏、容器残留或其他离子，须单独登记；不能用调整膜参数吸收闭合误差。容许偏差应由天平、移液器、电导校准和空白传播确定，不在看到膜组差异后补定。

## 4. 面积与通量

有效面积 \(A_{eff}\) 必须来自夹具开孔、密封接触和实际暴露区域的记录。只有在校准、体积和取样补液闭合后，才允许计算接收侧累计转移量和区间平均通量：

\[
J_k=\frac{\Delta N_{receiver,k}^{corrected}}{A_{eff}\,\Delta t_k}
\]

其中 \(\Delta N_{receiver,k}^{corrected}\) 必须包含取样带走及补液带入的盐量。旧曲线在这些输入缺失时继续保留为电导—时间曲线，不生成名义通量。

## 5. 空白体系

| 空白 | 主要检查对象 | 与主样必须匹配的记录 |
|---|---|---|
| 无膜全过程空白 | 混合、扩散边界、装置背景和操作污染 | 液体、温度、体积、搅拌、取样补液和时长 |
| 不透膜空白 | 密封旁路、夹具泄漏和外层串扰 | 开孔、压紧、密封材料和装配顺序 |
| 液体/容器空白 | 浸出、蒸发和容器污染 | 液体批次、容器批次、前后质量或体积 |
| 电极/盐桥空白 | 浓差电位的偏置、漂移和液接影响 | 对称液、左右互换、漂移时间和电极状态 |

空白只用于限定装置背景和失败条件，不能单独反演有膜运行中的真实边界层厚度。

## 6. 最小失败判据框架

以下事件至少触发 `review`，是否排除须在正式开测前给出基于仪器能力的数值阈值：

1. 校准区间外读数或校准漂移；
2. 盐量或体积闭合超界；
3. 无膜或不透膜空白异常；
4. 可见泄漏、膜破损、折皱或密封越界；
5. 温度、搅拌、取样或补液偏离计划；
6. 样品 ID、母膜映射或原始文件缺失；
7. 电极、盐桥或液接空白超界。

失败记录必须保留原始数据、原因、决定时间和决定人。不得删除失败运行后重新编号。

## 7. 当前可执行决定

1. 历史盐曲线继续只做描述性 QC，不计算正式浓度、通量或渗透率。
2. 导师可先给出 provisional 的体积、面积、温度和操作条件；收到后可运行试算并输出敏感性范围。
3. 正式实验仍需原始校准、空白和样品映射，才能把 provisional 结果升级为 measured 结果。
4. 本草案为 B21 预备材料；B20 协议和实验装置确定前，B21 状态保持“待开始”。

## 8. 可执行计算入口

`src/data_ingest/mass_balance.py` 已实现体积更新、取样/补液校正、盐量闭合误差和区间平均通量的无参数函数。函数不预置面积、体积、浓度或阈值，只接受外部输入并检查非负量及正面积/时间。`test_mass_balance.py` 使用明确的合成算术例验证取样加回、补液扣除和通量单位关系；测试值不是本项目实验数据。

`src/data_ingest/conductivity_calibration_template.csv` 只含校准登记表头。`conductivity_calibration.py` 检查同一校准内的单位、温度基准、温度补偿状态及电导—浓度单调性，并只在校准区间内做分段线性插值；区间外输入直接失败，不作外推。插值形式属于数据接入工具，不预设真实仪器的校准函数。

`src/data_ingest/salt_transport_run_template.csv` 固定逐时间点运行日志，覆盖两侧电导、体积、取样、补液、补液浓度、温度、有效面积、blank、夹具和泄漏标记。`validate_salt_transport_runs.py` 检查数值非负、时间唯一且有序，以及同一次运行中的样品、单位、校准、面积、blank 和夹具一致性；空模板不含虚构运行。

每行固定为 `record_phase=pre_event`：先记录该时点取样/补液前的两侧电导和体积，再登记该时点将执行的取样与补液。计算当前池内盐量时只累计此前时点已经发生的取样/补液，随后再将本行事件加入下一时点的累计量，防止重复计数。

每次运行同时固定 `receiver_side=left|right`，用于区分接收池累计转移量；同一运行中不得改变接收侧。

`src/data_ingest/process_salt_transport_runs.py` 将通过校验的运行日志与校准表连接，换算两侧浓度，按 `pre_event` 顺序校正取样/补液，计算 SI 制盐量闭合、接收侧累计转移量和累计平均通量。当前仅支持明确登记的 `mol/L` 或 `mmol/L`、`L` 或 `mL`、`m2` 或 `cm2`、`s`/`min`/`h`，并要求运行温度与校准温度完全一致。所有输出继续标记 `mechanistic_fit_authorized=false`。

`src/data_ingest/blank_registry_template.csv` 和 `validate_blank_registry.py` 分别登记、校验无膜、不透膜、液体/容器和电极/盐桥空白。盐输运最低空白集合要求 ready 的无膜与不透膜空白；电位最低集合要求 ready 的电极/盐桥空白。液体/容器空白作为盐输运补充检查单独报告。登记齐全仍不替代空白结果和数值阈值审查。

`src/data_ingest/quality_threshold_template.csv` 和 `validate_quality_thresholds.py` 用于在查看 O/S/W 处理差异前登记校准漂移、盐量闭合、无膜空白、不透膜空白和温度偏差阈值。ready 阈值必须有比较方向、数值界限、单位、依据记录、处置动作、批准人和批准时间；planned 阈值允许显式 `unknown`。阈值集合齐全仍不自动授权实验。

同一模块提供包含边界值的机械判定函数，支持绝对值上限、普通上限、下限和双侧区间。非有限数、缺失界限或反向区间直接失败，不进入人工选择性判断。

阈值集合 ready 后，可将同名质量指标批量送入执行函数；每项输出固定为 `pass` 或预声明的 `review`/`exclude`。缺任一指标时整批失败，禁止只评价有利指标。执行结果仍标记为不自动授权实验。
