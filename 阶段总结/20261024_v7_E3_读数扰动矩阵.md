# v7 E3 冻结读数扰动矩阵

## 问题、输入与计算

检验已有B原读数受到两档人为扰动后，固定NS候选的拟合、预测和既有失配如何变化。按v7任务包04与configs/frozen_spec.json，η=0.01/0.05，种子8101–8106，共12任务；每项仅用四个预设起点，最多200次实际目标函数调用/起点。σ=max(0.01,η|κ|) μS/cm，先对包括0 min基线在内的原读数κ加扰动，再对同膜减去同一个已扰动基线；负增量保留。这里η为人为情景，不是仪器误差估计。

直接复核的实际命令示例：

    .\.venv\Scripts\python.exe src\effective_network_model\v7_e3_fit_start.py 0.05 8106 0
    .\.venv\Scripts\python.exe src\effective_network_model\v7_e3_report_task.py 0.05 8106

每项实际调用次数和状态见WP5/v7_E3_fit_runs.jsonl、WP5/v7_E3_task_reports.jsonl；504行拟合点见WP5/v7_E3_point_predictions.csv。扰动输入见WP5/v7_E3_perturbed_B_readings.csv。逐项运行命令和关键数值见WP5/v7_E3_读数扰动准备记录.md。旧13包和v7输入未改。

48个起点均solver_success；每任务最佳目标L重算一致，另外三个成功起点均在冻结1%相对L内。所有任务的log10α都在上界1%邻域，说明该参数仍受界限约束，不能据此称其被真实数据稳定辨识。最小状态均为0，没有负状态。η=0.05、seed8104的350 nm/20 min扰动后增量为−0.06866383963944345 μS/cm，按规则保留。

12份扰动读数中，200/350 nm的120 min增量比均大于1（1.135030–1.299215）；对应NS拟合比也均大于1（1.622735–1.679307）。这个排序在预设抽样情景中没有翻转；有限种子不能推出对全部扰动的确定性稳健结论。

对未扰动B原读数，12个重拟合的asinh误差为2.039303–2.039426。2600 nm的120 min拟合增量/原增量仅0.012948–0.013362，既有严重失配没有被读数扰动或重拟合解除。E3技术稳定不改变第4步模型改进门槛未过、E2整体不记PASS、真实PE辨识未证实的判断。没有从E3导出可投稿的机制解释。
