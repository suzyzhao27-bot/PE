# 18A/18B 接入：开算边界与证据缺口

2026-10-26。依据`原始资料/赵珈绮/00_v9暂缓全面开算_20261026.txt`、18A的00/01与18B的00–03、独立审查记录，核对正式看板和现行研究问题。本文件记录项目决策，不替代两个原始审查包，也不构成新学生任务书。

## 研究决定

- 从已观察到的薄厚组盐通过差异出发，撤回“荷电造成排盐”的预设。荷电保留竞争地位。
- v9原“减少同号邻面抑制”机制当前不具备全面开算依据。18A的约0.35%增荷、约0.18 mV势变化是特定同储液、同化学、对称平板近中性参照；不能外推成任意方纤维膜的严格上界，也不能把ζ或KPFM直接等同PB表面势。
- 18B优先检验湿态贯通水路可达性与瓶颈假设。若主张尺寸/脱水屏障，必须约束大孔自由水旁路；很少的近自由水通路本身亦可解释低总盐通过。现有总量数据不能唯一识别两者。

## B曲线共同时间形状的解析检查（续接模块）

**对象与公式：** 仅取工作区`data/processed/salt_transport/salt_transport_tidy.csv`中`Polymer_salt_2h.opju / Book1 / Sheet1`六条PE曲线的0、60、120 min原电导，定义`F60=[κ(60)−κ(0)]/[κ(120)−κ(0)]`。这是单条曲线相对进程，无电导至浓度或通量换算；没有拟合新参数。

| 名义厚度 / nm | F60 |
|---:|---:|
| 65 | 0.520492 |
| 120 | 0.485852 |
| 200 | 0.100575 |
| 350 | 0.504626 |
| 700 | 0.624155 |
| 2600 | 0.523198 |

若六条曲线仅有各自基线和幅度、共享同一时间函数`κ_i(t)=a_i+b_i f(t)`，则所有`F60`必须相同。现有原读数的最大差为0.523580（200与700 nm）；即使为共同`F60`任选一个值，六条中至少一条的绝对归一化残差不小于0.261790。这是代数上的描述性不相容，**不是统计显著性检验**：缺少逐曲线测量误差、独立膜重复及运行日志，不能排除测量或装样状态差异，更不能据此命名润湿、瓶颈或荷电机制。200 nm在60至80 min由2.93升至11.24 μS/cm，原表时间列为60/80 min；该突变尤其需要原记录核对。

**决策用途：** 后续任何只给各膜不同幅度、却强制共用一个时间进程的模型，须先处理这一原读数差异和测量不确定性；不得把共享形状拟合失败直接当作H_A或H_B的验证。该检查不改变同片证据门槛，不授权新模型矩阵。

## 200 nm跃升的来源层级核对（续接模块）

**原工程续核：** 已用本机Origin COM只读加载`原始资料/赵珈绮/01_研究框架与资料_v2/05_真实数据_v1核查/source_snapshots/Polymer_salt_2h.opju`，从`[Book1]Sheet1`直接取得第4/5行C/E列：`60 min / 2.93`、`80 min / 11.24`；E列注释为`200 nm`。COM数组是1起始下标，首次取错单元格的输出已废弃，按数组边界改正后的结果才用于本判定。运行未发出保存指令。

## 共同时间形状结论的单曲线敏感性（续接模块）

沿用上节已定义的Book1六条`F60`，只做“暂不使用200 nm读数”的诊断对照，不从原表删除或更改该曲线。六条全部保留时，`F60`范围0.100575–0.624155，跨度0.523580；暂不使用200 nm后，余五条范围0.485852–0.624155，跨度0.138303。共同`F60`对五条的最小最大绝对残差下界为0.069151，仍非精确共形。

**边界：** 五条范围缩小，说明先前强烈的形状冲突对200 nm有明显敏感性；即使原工程确认其读数，也不能因无重复误差而把它判为应剔除的异常点。余五条的非零差异同样不能在未知误差下作统计拒绝。以后若将“共同时间形状不成立”作为材料结论，需独立膜/仪器误差及逐曲线运行记录；本次只把它作为模型设计的诊断门槛，不能拿来区分H_A/H_B。

## 六条B曲线的最大分段增长定位（续接模块）

从现有`data/processed/salt_transport/salt_transport_tidy.csv`只取Book1六条PE，按各曲线**实际时间列**计算相邻两点的`Δκ/Δt`；每条列出最大分段斜率所在区间及该段占其0–120 min总电导增量的比例。这是读数描述，不是瞬时通量、材料常数或动力学拟合。

| 厚度标签 / nm | 最大斜率区间 / min | 该段Δκ / μS cm⁻¹ | 占全段增量 |
|---:|---:|---:|---:|
| 65 | 40–60 | 5.89 | 34.5% |
| 120 | 100–120 | 2.73 | 18.8% |
| 200 | 60–80 | 8.31 | 59.7% |
| 350 | 40–60 | 5.68 | 47.8% |
| 700 | 20–40 | 28.10 | 32.2% |
| 2600 | 20–40 | 632.85 | 46.4% |

同表PC对照在40–60与60–80 min的增量分别为88.1和85.0 μS/cm，未见与200 nm同样突出的60–80 min相对跃升；PC与六张PE是否同次运行未认证，不能据此排除仪器、取样或混合因素。65 nm第5点是85 min，其他相关PE列第5点为80 min；本表用实际时间跨度排序斜率，没有把65 nm强行改作80 min。

**判定：** 保存的曲线没有一个六膜共有的最大增长区间；200 nm也不是唯一有集中增长段的膜。区间位置不能排列成严格的薄厚单调规律，且每曲线只有一组读数、独立重复未知。后续查原实验日志时，优先定位200 nm的60–80 min、350 nm的40–60 min及2600 nm的20–40 min运行事件；不因峰段时间不同就断言湿态通路逐膜开启。无新模型矩阵或参数扫描。

## 可辨识性所需的第二观测量（设计端条件判据）

定向盘点当前`data/processed/`文件名与18B证据入口，未定位可与B六条盐曲线认证为同片的水通量或中性示踪测量表。`data/processed/figures/v4_donnan_w_flux.png`由`src/long_tube_diagnostic/plot_v4_donnan_w_flux.py`绘制旧v4情景，是模型图，不能算独立功能观测。这项盘点限于现有处理数据与已索引18B来源，不声称查遍未归档实验本。

若将来有**同片、同湿态、同装置或可扣除外部阻力**的NaCl共同盐传导量`g_s`和非吸附中性示踪传导量`g_t`，可定义`χ_s=g_s h/D_s`、`χ_t=g_t h/D_t`；其中`g=J/Δc`单位m/s，`D_s`为相应条件下的体相共同盐扩散量，`D_t`为体相示踪扩散量，`h`单位m。在“两者穿过相同少量自由水通路、可忽略各自分配/阻滞”的H_A极限中，`χ_s≈χ_t`；有效面积和路径长度作为共因子相消。若`χ_s≪χ_t`，该简单H_A极限受限制，提示存在物种选择性代价，但**不能单独指定为几何瓶颈、脱水、介电或荷电**。示踪物尺寸、吸附、分配、浓差及外部阻力需要独立约束；压力水通量也不能未经转换直接替代扩散示踪量。

当前只有B盐电导代理量，连`g_s`的实际校准、有效面积及逐曲线体积/运行条件都未闭合；上述比值**不能从现有文件计算**。这是未来证据准入的必要设计条件，不是新数据、学生任务书或本轮新实验授权。现有H_A/H_B不可辨识和v9暂缓决定保持。

## 内部稿可用主张与不可写主张（续接模块）

**可用的结果表述：** “保存的B组Book1六条PE曲线在0–120 min的接收侧电导增量中，65–350 nm四条为11.89–17.08 μS/cm，700 nm为87.27 μS/cm，2600 nm为1363.25 μS/cm。薄端四条不严格单调；各曲线时间形状也不同，200 nm在60–80 min出现其最大分段增长。200 nm这两个点已在原Origin工程核对。该观测是共同盐转移的电导代理，而非单离子选择性或压力截留率。” 单位对部分列来自同表继承；独立膜重复、校准和实际面积仍未认证，正式论文使用前须标明这些限制。

**可用的条件讨论：** “在孔数、湿态通路、壁面性质和实验边界均不变的参照下，仅缩短扩散路长不会使传导下降。因此观察到的薄厚组差异需要至少一个与厚度共变的结构、可达性、界面分配或测量状态因素；现有数据尚不能选定哪一个。” 这不是证明本膜已存在亚纳米瓶颈、加工因果或薄化增荷。

**当前不得写成结果：** B曲线给出了Na⁺/Cl⁻分离系数或压力盐截留率；R曲线是已知润湿重复（Book2元数据只写`R65/R700/R2600`）；本盐系列已测到湿态亚纳米孔喉；少量自由水旁路或离子屏障已被唯一识别；v9邻面抑制机制已获材料验证；已完成可投稿的机制论文。这里的“不准入”是现有证据边界，不是宣称相应机制在真实PE中不存在。

本轮没有新实验、拟合或论文投稿。该段供未来内部稿引用；v9的历史稿及18A/18B原件不改写。下一篇机制稿需先闭合样品身份、运行日志/误差与独立功能约束，再决定主张强度。
