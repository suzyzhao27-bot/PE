# v5 共享边界的离散重拟合敏感性

**日期：** 2026-10-17

**性质：** 已有六端点的内部敏感性计算；不改变导师 v5 参考边界 `r=0`

## 问题与方法

导师 v5 已比较 `r=0` 与固定表面值极限 `r=1`，但稳定自由能的 `Cq≥0` 还允许中间 Robin 边界。设 `β=Bq/ell>0`，则 `r=(Cq−β)/(Cq+β)`，即 `Cq/β=(1+r)/(1−r)`。本轮预设 `r=−0.5/0/0.25/0.5/0.75/1` 六个离散值；每个值分别重拟合同一组六个 0/120 min 电导增量的 `ws`、`ell` 与共同幅值。没有将 `r` 当连续自由参数，也没有逐厚度调参。

本工作区入口为 `src/effective_network_model/boundary_refit_check.py`。它复用交接 `core` 的场公式，用独立自适应积分计算阻力；沿用导师拟合范围 `0.01≤ws≤100`、`0.1≤ell≤10000 nm`，对数残差、共同幅值解析消去、多起点有界优化。L-BFGS-B 在个别留一子集报告异常终止时，以同一候选点运行有界 Powell，再必要时用固定随机种子的全局优化；仅接受收敛且未增大目标值的结果。极端试探点的自适应积分若发出精度警告，试探值改由 core 积分提供；所有最终解均强制通过无警告的自适应积分与 core 独立核对。脚本不写入原始资料或结果文件。最优点与 `core` Simpson 积分的最大 log 阻力差不超过 `4.1×10^-7`；`r=0` 复现 `ws≈7.03979`、`ell≈893.954 nm`，`r=1` 复现导师 log RMSE `1.06446`。

### 350/200 nm 局部排序能否靠选边界修复

使用上表六个**各自全六点重拟合**的精确参数，计算同一模型下 `P(350)/P(200)=exp[log R(200)−log R(350)]`；共同幅值抵消。旧端点的观测增量比为 `11.89/13.92=0.854167`。

| 固定 `r` | 模型 `350/200 nm` 比值 |
|---:|---:|
| −0.5 | 1.492061 |
| 0 | 1.497433 |
| 0.25 | 1.481058 |
| 0.5 | 1.450384 |
| 0.75 | 1.426465 |
| 1 | 1.568712 |

六个预设边界的全数据最佳拟合都给 `350/200>1`，与旧端点 `0.854167<1` 的局部排序相反；训练误差最低的 `r=0.75` 也未修复。把电导增量比与模型相对 `P` 比较仍依赖共同校准、测量面积/体积、时长与驱动力近似。计算只覆盖这六个离散边界及既定参数范围，不证明任何连续 `r` 或其他结构模型都不可能匹配。旧标签的独立样品、实验条件和误差条未核实，不能据此声明统计显著或确定物理原因。

## 留一压力检查与限制

按各自固定 `r` 对六个厚度分别留一、重拟合其余五点，`r=0` 的留一 log RMSE 为 `2.68345`，`r=0.75` 为 `1.87978`。但留出 2600 nm 时，`r=0.75` 仍高估 `90.88` 倍（`r=0` 为 `616.54` 倍）；留出 350 nm 仍高估 `1.60` 倍，留出 700 nm 低估至 `0.476` 倍。`r=0.75` 是看过全六点训练误差后选作留一对照的值，这种留一分数存在边界选择的信息泄漏，**不是独立选模验证**。

六个厚度标签不是六个已验证独立母膜重复，缺少误差模型与未参与选择的新数据。本轮只证明边界选择和参数辨识敏感；不新增真实边界结论，不把训练改善称作预测成功。正式主模型继续保留 `r=0`，同时报告本对照及原有失败。

### 参考边界留一误差的厚度集中度

直接读取导师已保存的 `fit/results/leave_one_out.csv` 中六个 `held_log_residual`，不重拟合。参考 `r=0` 的六折留一 log RMSE 为 `2.683447`；从**同一批已算出的留出残差**中暂不计 2600 nm，余五项的 log RMSE 为 `0.622252`。2600 nm 一项贡献六项平方 log 残差之和的 `95.5191%`。因此总留一分数主要受最厚标签控制，单独汇报总分会掩盖其余五个留出点的误差结构。这个五项数值只是已保存残差的分解，不是删除厚点后重新训练一个五厚度模型，也不是对新样品的性能估计。其他留出点中，700 nm 的绝对 log 残差最大，为 `1.163037`（预测/观测 `0.312536`），仍不能称余下五点都预测准确。厚点的样品和测量条件、误差范围未核实，集中度不能判定失败来源。

## 嵌套留一：每折只用五点选边界

为避免全六点先选 `r=0.75` 再把固定边界留一当作独立选模验证，每折先排除一个厚度，再在其余五点上分别拟合六个预设 `r`，按五点训练 log RMSE 选边界，最后只预测留出点。

|---:|---:|---:|
| 65 nm | 0.75 | 1.130 |
| 120 nm | 0.75 | 0.839 |
| 200 nm | 0.75 | 0.805 |

嵌套留一 log RMSE 为 `1.92503`。选择的边界随留出厚度改变；最厚点仍严重失败。此内部检查避免每折直接使用留出值选择边界，但边界候选和分析均属事后提出，仍非独立外部验证，也不能据此改写正式参考模型。
