# v5 共享边界的离散重拟合敏感性

**日期：** 2026-10-17

**性质：** 已有六端点的内部敏感性计算；不改变导师 v5 参考边界 `r=0`

## 问题与方法

导师 v5 已比较 `r=0` 与固定表面值极限 `r=1`，但稳定自由能的 `Cq≥0` 还允许中间 Robin 边界。设 `β=Bq/ell>0`，则 `r=(Cq−β)/(Cq+β)`，即 `Cq/β=(1+r)/(1−r)`。本轮预设 `r=−0.5/0/0.25/0.5/0.75/1` 六个离散值；每个值分别重拟合同一组六个 0/120 min 电导增量的 `ws`、`ell` 与共同幅值。没有将 `r` 当连续自由参数，也没有逐厚度调参。

本工作区入口为 `src/effective_network_model/boundary_refit_check.py`。它复用交接 `core` 的场公式，用独立自适应积分计算阻力；沿用导师拟合范围 `0.01≤ws≤100`、`0.1≤ell≤10000 nm`，对数残差、共同幅值解析消去、多起点有界优化。L-BFGS-B 在个别留一子集报告异常终止时，以同一候选点运行有界 Powell，再必要时用固定随机种子的全局优化；仅接受收敛且未增大目标值的结果。极端试探点的自适应积分若发出精度警告，试探值改由 core 积分提供；所有最终解均强制通过无警告的自适应积分与 core 独立核对。脚本不写入原始资料或结果文件。最优点与 `core` Simpson 积分的最大 log 阻力差不超过 `4.1×10^-7`；`r=0` 复现 `ws≈7.03979`、`ell≈893.954 nm`，`r=1` 复现导师 log RMSE `1.06446`。

### 350/200 nm 局部排序能否靠选边界修复

使用上表六个**各自全六点重拟合**的精确参数，计算同一模型下 `P(350)/P(200)=exp[log R(200)−log R(350)]`；共同幅值抵消。旧端点的观测增量比为 `11.89/13.92=0.854167`。

| 固定 `r` | 模型 `350/200 nm` 比值 |
|---:|---:|
| −0.5 | 1.492061 |
| 0 | 1.497433 |
| 0.25 | 1.481058 |
| 0.5 | 1.450384 |
| 0.75 | 1.426465 |
| 1 | 1.568712 |

六个预设边界的全数据最佳拟合都给 `350/200>1`，与旧端点 `0.854167<1` 的局部排序相反；训练误差最低的 `r=0.75` 也未修复。把电导增量比与模型相对 `P` 比较仍依赖共同校准、测量面积/体积、时长与驱动力近似。计算只覆盖这六个离散边界及既定参数范围，不证明任何连续 `r` 或其他结构模型都不可能匹配。旧标签的独立样品、实验条件和误差条未核实，不能据此声明统计显著或确定物理原因。

**跨列比例的条件阈值：** 原表 E（200 nm）、F（350 nm）未单列单位。令 `s` 表示从原表 350/200 增量比到可比物理量比所需的相对正比例修正，即修正后比值为 `s×(11.89/13.92)`；这只是记号，不是已测校准系数。若仅要把旧端点的 `350/200<1` 排序翻为 `>1`，须 `s>1/0.854167=1.170732`。若要使它恰好等于参考 `r=0` 全六点训练模型的 `1.497433`，须 `s=1.753092`。因此“六个离散边界均未修复排序”只对**原表共同可比的比例假设**成立；未知的跨列单位、校准或几何不能被数值拟合代替确认。这些阈值不表示实验实际有 17% 或 75% 的偏差，也不证明某种修正应被采用。

## 留一压力检查与限制

按各自固定 `r` 对六个厚度分别留一、重拟合其余五点，`r=0` 的留一 log RMSE 为 `2.68345`，`r=0.75` 为 `1.87978`。但留出 2600 nm 时，`r=0.75` 仍高估 `90.88` 倍（`r=0` 为 `616.54` 倍）；留出 350 nm 仍高估 `1.60` 倍，留出 700 nm 低估至 `0.476` 倍。`r=0.75` 是看过全六点训练误差后选作留一对照的值，这种留一分数存在边界选择的信息泄漏，**不是独立选模验证**。

六个厚度标签不是六个已验证独立母膜重复，缺少误差模型与未参与选择的新数据。本轮只证明边界选择和参数辨识敏感；不新增真实边界结论，不把训练改善称作预测成功。正式主模型继续保留 `r=0`，同时报告本对照及原有失败。

### 参考边界留一误差的厚度集中度

直接读取导师已保存的 `fit/results/leave_one_out.csv` 中六个 `held_log_residual`，不重拟合。参考 `r=0` 的六折留一 log RMSE 为 `2.683447`；从**同一批已算出的留出残差**中暂不计 2600 nm，余五项的 log RMSE 为 `0.622252`。2600 nm 一项贡献六项平方 log 残差之和的 `95.5191%`。因此总留一分数主要受最厚标签控制，单独汇报总分会掩盖其余五个留出点的误差结构。这个五项数值只是已保存残差的分解，不是删除厚点后重新训练一个五厚度模型，也不是对新样品的性能估计。其他留出点中，700 nm 的绝对 log 残差最大，为 `1.163037`（预测/观测 `0.312536`），仍不能称余下五点都预测准确。厚点的样品和测量条件、误差范围未核实，集中度不能判定失败来源。

### 同折留一基线对照

导师交付的同一 `leave_one_out.csv` 还保存三种基线在**相同六个留出厚度、各自只用另外五点调共同幅值**时的 log 残差。`D/h` 基线阻力为 `h`；固定入口基线为 `h+πa/2`；共享正的常数进入能基线为 `h exp(w)+πa/2`，其中最后一种每折在五点内优化 `w`。直接对 CSV 残差求均方根，不重跑拟合：

| 模型 | 六折留出 log RMSE | 不计 2600 nm 后的五项现成残差 log RMSE |
|---|---:|---:|
| 共享有效场，参考 `r=0` | 2.683447 | 0.622252 |
| 常 `D/h` | 3.380626 | 2.158242 |
| `D/(h+πa/2)` | 3.243708 | 2.027533 |
| 共享常正进入能 | 3.243708 | 2.027533 |

在这组六个旧标签的**内部留一**中，参考模型六折合计误差低于三种交付基线；但 `2.683447` 仍很大，最厚点预测/观测 `616.54`，不能据相对改善声称厚端预测成功。五项列只是相同六折残差的事后分解，不是仅用五种厚度重新设计的交叉验证。三个基线的定义和逐折训练方式核对交付 `fit_shared_overlap.py`，结果数值取交付 CSV；六标签不是已证实独立实验重复，因此对照不提供外部预测能力或模型机制的统计证据。

## 两个关键比例的定向约束检验（2026-10-18）

上面的六点最小误差拟合和六个离散边界均没再现旧 350/200 排序；这**不等于**整个 `r=0` 场形绝不可能出现该排序。为区分“模型形状不可能”与“多点取舍”，固定 `r=0, a=25 nm`、同一 `ws/ell`，只要求两个旧端点比例 `350/200=11.89/13.92` 和 `2600/700=1363.25/87.27` 同时成立。`src/effective_network_model/ratio_constraint_check.py` 用导师 core 的阻力积分及原 Book1 六个 0/120 min 增量求这两个共享参数；输出 `data/processed/v5_ratio_constraint_check.csv`。没有给任何膜单独参数，也没有重新定义导师参考拟合。

从参考参数作初值，在导师原参数范围内找到条件解 `ws=11.328905328 kBT`、`ell=4040.278845 nm`。细积分核对的两个目标比值分别与旧值 `0.854166667`、`15.621061075` 一致。这说明**所检验的两个局部比例本身可以被同一场形同时满足**，不能宣称单凭它们就否定 `r=0` 方程。

关键的未用于求解的第三个相邻比例 `700/350`，该解只预测 `1.230131968`，旧增量比为 `7.339781329`，模型/旧值 `0.167597904`，约低 `5.97` 倍。也就是说把两处特征压准会丢失中间跃升，揭示旧厚度族对同一场形的多重约束。该解基于已看过的旧数据挑选比例，不是独立预测或新“最佳模型”；`ell≈4.04 μm` 也只是条件解，不是已测网络相关长度。其他参数解或扩展机制未被此局部求解穷尽。跨列端点比仍受单位、校准、几何和样品身份限制，不能赋予统计显著性。

三比例折中改善这**三个特定比例**的合计误差，却将最薄的关键 350/200 排序错误扩大到模型/旧比 `2.1671`，并没有使三段全都吻合。导师参考解优化的是**六个端点的 log 增量**，不是这三个相邻比例，因此两个目标函数的数值不能作为同一预测竞赛。多初值优化不是整个连续参数域的严格不可行证明；本检验显示在当前局部求解与冻结结构下误差如何转移。`65/120` 的模型比在参考/两比例/三比例选择下分别为 `0.811607/0.630515/0.903703`，旧比 `0.848361`；这些均为同一旧表内部比较，并非新样品验证。

### 最厚点对参数辨识的局部作用（2026-10-18）

留出 2600 nm 时 `ell` 撞上拟合上界、预测严重失败；这可能来自该点为参数提供的特殊尺度约束。为定量区分，`src/effective_network_model/parameter_sensitivity.py` 在**冻结的六点参考参数处**对各厚度的 `ln P` 求 `ln ws_ref`、`ln ell` 两列局部导数。各子集先减去自己的均值，使未知共同幅值不进入分析，再用两列灵敏度矩阵的奇异值表示两种参数变化是否容易彼此混淆。输出 `data/processed/v5_parameter_sensitivity.csv` 含全六点和逐点留出共七行。

全六点较弱奇异值 `1.527431`，条件数 `4.240715`；留出 2600 nm 后分别变为 `0.162182`、`22.906246`。较弱约束降至原来的约 `10.62%`，条件数增至约 `5.40` 倍；留出其他标签时条件数约 `4.05–6.80`。这说明在参考解附近，最厚点显著帮助分开 `ws` 与 `ell` 的效应，和其留一重拟合的不稳定相互呼应。

这是固定参考参数处的**局部灵敏度几何**，不是五点重新拟合后的参数置信区间、误差条、全局可辨识性证明或独立预测验证。导数由 `1e−4` 与 `5e−5` 两个 log 步长核对稳定；资料缺测量误差，不能由条件数推出真实参数不确定度。

### 五点弱方向对留出点的预测放大（2026-10-18）

上述条件数说明五点难区分两参数，但未直接量化**这个难区分的方向会怎样影响留出点**。同一脚本加 `--leverage-output data/processed/v5_heldout_leverage.csv`：每次用其余五点的中心化 log 灵敏度找较弱的参数组合方向；计算该方向对五点预测的均方根变化，以及对留出点相对五点均值预测的变化。二者比值衡量局部外推放大，不含旧观测误差。

| 留出厚度 / nm | 留出点变化 / 五点内部均方根变化 |
|---:|---:|
| 65 | 1.359 |
| 120 | 0.623 |
| 200 | 0.046 |
| 350 | 0.938 |
| 700 | 3.427 |
| 2600 | **40.022** |

对 2600 nm，沿五点最难辨认的参数方向做一个**足够小的同等 log 参数位移**，2600 nm 相对预测变化约为五点内部典型变化的 40 倍。这提供了“只看五点仍能拟合、最厚点却极不稳”的局部数学解释。它**不是** 2600 nm 的观测误差倍率，也不是可外推的线性范围；大位移和五点重拟合需另作非线性计算，导师留一结果已记录其实际失败。

### 200/350 nm 局部尺度差异的条件门槛（2026-10-18）

冻结导师 `r=0, ws_ref=7.039790538, ell=893.953885 nm, a_ref=25 nm`，将 200 nm 的 `a` 固定在参考值，只求 350 nm 的尺度在预设 `ws(a)=ws_ref×25/a` 下何时使 `P350/P200` 从原参考的 `1.497433` 降到 `1`，以及旧端点条件比 `0.854167`。`src/effective_network_model/thickness_balance.py --local-scale-threshold-output` 得到 `a350=24.162949/23.851175 nm`，即相对参考值下降 `3.348%/4.595%`。若只让几何入口项的 `a` 改变，保持 `ws` 不变，两处模型比仍约 `1.497433`。因此数值门槛主要量化的是**预设场强反比尺度闭合**，不是直接几何口径；小尺度差会被强能垒指数放大。

这是针对一个既有失配的**必要条件诊断**，并未建立可同时解释六厚度、留一失败和时间曲线的膜间尺度规律；不将反求值用作后续逐膜拟合。局部湿态尺度及 `ws(a)` 关系都缺独立测量，旧端点比例还以跨列可比为前提。可复算表为 `data/processed/v5_local_scale_threshold.csv`。

### 跨图机制判别：目前单一改动各能解释什么（2026-10-18）

把图一的 200/350 排序、图四的归一化曲线交叉和最厚点留一失败放在一起，可以给出以下**必要条件**。表中“不能”仅限写明的简化模型，不排除更复杂的耦合机制。

| 单一改动或解释 | 对 200/350 旧端点比 | 对归一化曲线交叉 | 尚缺的独立约束 |
|---|---|---|---|
| 每列固定乘性校准差异 | 相对修正 `s>1.170732` 可翻转旧排序；匹配参考比须 `s=1.753092`，均非已确认修正 | 列内归一化后乘性因子消去，**不能**移除已记录的 13/15 对交叉 | 六列校准、体积、几何、时间标签和误差记录 |
| 同一非负时间开启函数，每膜仅固定强弱不同 | 可以改变各时刻共同速度，不能单独决定厚度端点链 | 同一有限池形式下曲线次序固定，**不能**产生交叉 | 各列时间轴与列内读数映射确认 |
| 各膜假定局部尺度 `a` 不同，沿图二 `ws∝1/a` | 单独 350 nm 的条件门槛为 `a350<24.162949 nm` 才会使模型比例小于 1；不等于已测差异 | 若尺度只改变固定传输强弱且共用时间历程，**不能**产生交叉 | 湿态有效通路尺度及 `ws(a)` 关系的独立证据 |
| 共享静态场只改全局 `ws、ell` | 两个挑选比例可同时匹配，但第三个 700/350 预测 `1.23` 对旧 `7.34`；三比例折中会扩大 350/200 失配 | 静态常 `P` 本身不解释已记录的时间反例 | 可比较的端点、独立厚度留出及动态过程约束 |

因此**单独**修正旧列幅值、加一个共同时间门函数或按图二闭合改变固定孔径，都不足以同时解决端点链与时间交叉。合理的下一步是先核对原实验元数据，并取得独立湿态结构或时间过程约束，再比较一个共享且可留出验证的耦合机制；当前没有证据选定具体微观原因。此表综合前述现有计算，未新增观测、参数或拟合。
