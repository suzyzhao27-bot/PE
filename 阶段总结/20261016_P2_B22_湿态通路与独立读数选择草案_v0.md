# P2/B22 湿态通路与独立读数选择草案 v0

**日期：** 2026-10-16  
**状态：** 预备草案；不代表方法已选定或 B22 已完成  
**目标：** 用至少一项独立化学读数和一项湿态通路约束，区分真实离子选择性、润湿/连通变化和电导测量假象。

## 1. 最小读数组合

### A. 独立 Na/Cl 端点

在盐输运实验的初始液、终点液和关键空白中分别测 Na 与 Cl。该读数用于：

- 检查电导变化是否主要来自目标 NaCl；
- 检查 Na、Cl 和总盐量闭合；
- 识别浸出物或其他离子对电导的贡献；
- 为电导—浓度换算提供独立核对。

具体分析方法由现有仪器、检出限、基体兼容性和样品体积决定。未确认方法前，不假定检出限或回收率。

### B. 中性湿态示踪

选择水溶、在实验 pH 和盐度下电中性、可独立定量且对 PE/夹具吸附可检查的示踪物。示踪用于约束湿态连通通路，不直接代表 NaCl 扩散系数。

每个候选示踪物必须先通过：

1. 自由溶液校准；
2. 容器、密封材料和膜的吸附/回收空白；
3. 稳定性和背景干扰检查；
4. 检出限与预期时间窗匹配检查。

带电示踪物不能作为“中性通路”证据。若无法确认电荷状态或吸附，结果只作辅助观察。

### C. 对称电解质下跨膜电导 G

在左右相同电解质条件下测跨膜 G，可辅助约束湿态导通和装置串联电阻。G 同时受几何、表面传导、浓度、温度和电极接口影响，因此不能单独换算孔隙率或湿态面积。

## 2. 选择顺序

1. 优先确认能否获得独立 Na 与 Cl 端点；这是电导特异性和盐量闭合的最低核对。
2. 再选择一个通过吸附空白的中性示踪，作为湿态连通通路约束。
3. 若已有稳定电极和夹具，再加入对称电解质 G；G 为联合约束，不替代化学端点或示踪。
4. 湿态成像、吸液质量或其他结构表征只作补充，除非能够给出与输运片对应的连通信息和不确定度。

## 3. 方法淘汰条件

出现以下任一情况时，候选方法不进入冻结协议：

- 校准范围不覆盖样品；
- blank 与样品信号同量级且无法稳定扣除；
- 回收率、重复性或漂移不能由预先规则接受；
- 样品体积需求破坏主实验体积闭合；
- 示踪物发生明显吸附、降解或电荷状态不明；
- 方法需要使用主实验结果后才能选择参数或阈值。

## 4. 最低记录字段

`method_id, analyte_or_tracer, charge_state_basis, instrument, calibration_id, matrix, sample_volume, max_sample_volume, sample_volume_unit, dilution, detection_limit, quantification_limit, calibration_lower_bound, calibration_upper_bound, expected_min_signal, expected_max_signal, measurement_unit, blank_id, recovery_check, adsorption_check, stability_check, raw_file, operator, input_level, status, exclusion_reason`

未知项写 `unknown`。provisional 方法可以用于流程演练，但不能写入正式机制结论。

## 5. 当前推荐的最小方案

在仪器信息尚未提供时，先保留三层设计：独立 Na/Cl 端点为最低化学核对；合格的中性示踪为湿态通路主约束；对称电解质 G 为辅助联合约束。最终方法、浓度、取样体积、检出限和阈值由实际仪器与空白试验确定。

## 6. 可执行记录接口

`src/data_ingest/independent_readout_template.csv` 只含方法登记表头，不含虚构仪器或示踪物。`validate_independent_readouts.py` 检查方法 ID、Na/Cl/中性示踪最低组合、输入等级、blank、回收、吸附、稳定性和 ready 状态；ready 方法还必须满足取样体积不超过预声明预算、稀释倍数为正、检出限不高于定量限、预期最低信号可定量且预期范围位于校准区间内。检出限允许低于最低校准标准。结构与数值门通过仍不自动授权实验。
