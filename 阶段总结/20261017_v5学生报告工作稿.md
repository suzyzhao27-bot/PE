# 超薄 PE 纤维膜盐转移的共享有效场模型：报告工作稿

**版本与责任边界：** 2026-10-17 本工作区辅助写作稿，供学生核对、改写和补上本人复算记录；不是学生已提交的论文或独立完成证明。以导师 v5.0.0 交接包和本工作区复现记录为数值来源。正式篇幅可按学校模板扩展至约 10–15 页，但不得用篇幅替代核验。

## 摘要（待学生复核后使用）

本工作基于已有超薄 PE 纤维膜盐转移记录，研究有效结构场能否在同一参数规则下解释厚度依赖。使用六个厚度标签的 0–120 min 电导增量，建立由稳定结构自由能、双面 Robin 边界、条件化局部尺度关系和离子共同进入能组成的降阶模型，并用有限二维 PNP 对空间能场实现作数值校核。三个共享拟合量给出六点训练 log RMSE `0.25445`，能再现低转移区和厚膜端量级上升；但 350 nm 预测/观测为 `1.68565`，留出 2600 nm 时为约 `616.54`。旧时间曲线还不满足常 `P` 有限池的条件形状下界。结果支持**有条件的有效模型解释**，不支持真实微观机制唯一识别、绝对渗透率或独立预测已验证的声明。

## 1. 研究问题与数据身份

核心问题不是“能否给每条曲线单独选一个能垒”，而是同一结构场与共享参数能否同时解释低转移区和厚膜端的上升。导师 v5.0.0 模型使用旧 `Polymer_salt_2h.opju` 的 Book1 导出；core、fit 两份输入与既有 Origin 导出为同一张表。六个 PE 厚度标签为 `65/120/200/350/700/2600 nm`，比较量为各列 `120 min−0 min` 的电导增量。它们不是六组新增实验，也未证实对应六张独立母膜。

电导增量只能在共同近线性校准、相同有效面积/接收体积和时长、且没有未计入取样与补液等条件下用于相对盐转移比较。旧记录未恢复这些条件的完整证据。因此本文不把模型共同幅值换算成旧实验真实绝对渗透率，也不给六点添加没有来源的误差条。原始资料与派生表的对应关系见 `复现记录_20261017_v5.md` 和 `阶段总结/P1_B11_Origin源数据解码与盐输运重建.md`。

已归档的 [Sun 等（2022）](https://doi.org/10.1002/adma.202107941) 和 [Wang 等（2023）](https://doi.org/10.1016/j.polymer.2023.126393) 可供学生写 PE 超薄膜制备、结构和盐转移的研究背景。两篇论文及其样品不能自动充当本稿六端点的独立复测或同一套装置元数据。现阶段正文的六端点仍只来自上述旧 Book1 表；引用范围和学生实际阅读状态须在交稿前另核。

## 2. 模型与可检验条件

取冻结的有效结构变量 `q(z)`。正的体项、梯度项和两侧表面项组成稳定二次自由能。变分得到 `ell²q″=q`，其中 `ell=sqrt(Bq/Aq)`；两侧 Robin 条件分别为 `−Bq q′(0)+Cq q(0)=Hq` 与 `Bq q′(h)+Cq q(h)=Hq`。对称解可写成

`w(z;h,a)=ws(a)[exp(−z/ell)+exp(−(h−z)/ell)]/[1+r exp(−h/ell)]`。

主模型选 `r=0`；该值是边界假设，不是从旧记录直接测出的界面状态。`h` 为膜厚标签，`a` 为条件化的局部水路尺度，`ell` 为有效网络场相关长度。闭合 `ws(a)=ws(25 nm)·25 nm/a` 借用表面积/体积的形式，不能将 `a` 或 `ell` 写作已测湿态孔喉或 Debye 长。

[Binder 与 Hohenberg（1972）](https://doi.org/10.1103/PhysRevB.6.3461) 讨论含表面项的现象学 Landau 理论和表面边界参数，可作为“体项加表面项”数学形式的背景；该文研究的是 Ising 模型自由表面，不提供 PE 膜的 `q`、`ell` 或 `r` 数值。本稿的具体边界式仍以导师 v5 推导和本工作区核对为依据。

将共同进入能加入两离子电化学势 `μ_i=RT ln(c_i/c_ref)+z_iFψ+RTw`。在无固定电荷且两离子等扩散系数的校核极限，化学势匹配给出膜侧浓度为浴液浓度乘 `exp(−w_side)`，通量满足 `J=D(c_L−c_R)/∫₀ʰexp[w(z)]dz`。加入独立入口阻力参考长度 `πa/2` 后，模型渗透率与总阻力成反比。厚化既延长路径，又降低双面场重叠；两项竞争允许厚度斜率改变符号。上述解析极限不是有限二维带电网络的完整解。

## 3. 计算方法与复现路径

六点比较只用一套 `ws_ref`、`ell` 和共同对数幅值，不逐厚度调参。拟合结果以对数残差衡量；留一重拟合必须只用另外五点，留出的点仅用于检验。固定参数的局部尺度扫描分别比较 `a=20/25/30 nm`；另一对照固定 `ws`，只改变入口长度，以拆开结构闭合和几何入口的作用。边界分析保留 `r=0` 参考，同时检查预设的稳定 Robin 边界，不因某个训练分数较低就替换主模型。

### 3.1 端点、目标函数与对照

每个厚度标签的端点量定义为 `y_i=κ_i(120 min)−κ_i(0 min)>0`。参考模型使用 `R_i=∫₀ʰⁱ exp[w(z;h_i,a_ref)]dz+πa_ref/2`，写作 `ŷ_i=A/R_i`；共同幅值 `A` 吸收扩散、校准、驱动力、几何与时长等尚未分别辨识的因子。以 `e_i=ln(ŷ_i/y_i)` 为残差，训练评分是 `sqrt(Σe_i²/n_train)`。在给定 `ws_ref`、`ell` 后，程序只用训练点解析求共同 `ln A`；`ws_ref` 与 `ell` 在既定范围内联合优化。六点全数据训练和每次五点训练的留一检验必须分开陈述。

程序中 `ws_ref` 的搜索边界为 `0.01–100`，`ell` 为 `0.1–10000 nm`；这是数值约束，不是参数的实验置信区间。积分和优化细节由 `fit/fit_shared_overlap.py` 固定。常 `D/h` 基线也在相同六端点上调共同幅值后比较，不能把两者训练分数差解释成独立预测证据。`a_ref=25 nm` 是冻结的参考局部尺度；扫描 `a` 时不重新拟合三个共享量。

### 3.2 数值校核与时间形状

有限二维 PNP 把同一共同进入能放进 Na/Cl 的电化学势和离散通量，并检查守恒、开路电流与边界能跳。它使用虚拟五排网络及给定 30/1 mM 条件，与降阶直孔拟合的几何不同，所以二维结果只检验给定方程和实现，不用于重新标定旧膜绝对通量。空间结果应连同同 `σ` 零能场分母、网格数和收敛状态报告。

时间形状检验另取同一旧表各列的 `f_i(t)=[κ_i(t)−κ_i(0)]/y_i`。在两池封闭、充分混合、固定比例电导响应与常 `P` 的条件下，非负有限池参数 `θ` 给出 `f_θ(t)=[1−exp(−θt/120)]/[1−exp(−θ)]≥t/120`；`θ=0` 取极限。检验只读 A/C 时间列共同确认的 `0/20/40/60/100/120 min` 行，跳过 `80/85 min` 歧义行。此下界是必要形状条件，不是对旧曲线的拟合；无误差条时只能陈述记录与条件模型不完全一致。

仓库工作副本位于 `src/effective_network_model/`，仓库外复算入口与依赖见该目录 README。学生可先使用 `-CoreOnly` 完成只需 Python 标准库的 core 两步复算，再在已有 NumPy/SciPy 环境中另用新输出目录运行完整六步；两种模式均生成标明模式、解释器、命令和退出码的 `run_record.json`。已有本机复算通过 core `12/12`、PNP 新 `7/7`、旧 `10/10` 项；六个共享场代表工况收敛。学生在本人设备运行后，应逐项核对六端点、log RMSE、留一失败和二维数值检查，并在正式稿写明解释器、命令、输出路径及任何不一致。本工作区的通过记录不能代替这一验收项。

## 4. 结果：成功与失败并列

| 厚度标签（nm） | 旧表电导增量 | 共享模型增量 | 预测/观测 |
|---:|---:|---:|---:|
| 65 | 17.08 | 15.7080 | 0.91967 |
| 120 | 14.49 | 12.7487 | 0.87983 |
| 200 | 13.92 | 13.3845 | 0.96153 |
| 350 | 11.89 | 20.0423 | 1.68565 |
| 700 | 87.27 | 64.6445 | 0.74074 |
| 2600 | 1363.25 | 1403.2928 | 1.02937 |

增量沿用交付数据表的电导口径；65/120 nm 有显式 `μS/cm` 列标签，其余列按同表关系继承，仍待实验记录确认。表中六点均参与共享拟合，不能把“预测”列误称为未见数据的预测。

六点训练 log RMSE 为 `0.25445`，常 `D/h` 基线为 `2.81719`。模型复现低转移区与厚膜端量级上升，但观测最低点在 350 nm，参考模型预测最低点约 141 nm。更直接的局部对比是：观测 `350/200 nm` 电导增量比为 `0.854167`，模型预测比为 `1.497433`，排序相反；两个比值的比为 `1.753092`。该诊断不重新拟合，也没有统计显著性声明。

这一排序比较以 E/F 两列的单位、校准和测量几何可比为前提。若用一个**未确认**的正相对比例 `s` 修正原表 `350/200` 比值，仅翻转其 `<1` 排序需要 `s>1.170732`；与参考模型比值完全相等则需 `s=1.753092`。阈值不是已发现的校准误差，也不能据此改动旧数据；它指出应优先核实的跨列信息。

留出 350 nm 时预测/观测约 `2.060`；留出 700 nm 时约 `0.313`；留出 2600 nm 时约 `616.54`，且重拟合 `ell` 触及 `10000 nm` 上界。固定 `r=0.75` 的全六点训练 log RMSE 可降至 `0.17741`，但留出最厚点仍高估 `90.88` 倍。嵌套留一选边界的综合留出 log RMSE 为 `1.92503`。训练改善和局部雅可比非零都不能消除厚端外推不稳定。

从参考 `r=0` 已保存的六个留出 log 残差分解，2600 nm 单项占平方 log 误差总和的 `95.5191%`；不计这一项**现成留出残差**时，其他五项的 log RMSE 为 `0.622252`。这并非删点重拟合或新的验证分数；700 nm 留出时仍低估到观测的 `0.313` 倍。完整计算口径见 `阶段总结/20261017_共享边界离散重拟合.md`。

同一交付 CSV 还记录相同六折的基线留出误差。参考共享场六折 log RMSE 为 `2.683447`，常 `D/h` 为 `3.380626`，固定入口 `D/(h+πa/2)` 为 `3.243708`，共享常正进入能也为 `3.243708`。参考模型在这组旧厚度的内部留一中优于三种基线，但最厚点仍是重大失败；这项相对对照不是新样品验证，不能单凭分数确认真实结构机制。

|---:|---:|---:|
| 65 | 0.85668 | 863.10 |
| 120 | 0.82961 | 872.96 |
| 200 | 0.95092 | 893.96 |
| 350 | 2.05953 | 777.88 |

| 2600 | 616.53896 | 10000.00（上界） |

该表直接按导师交付 `fit/results/leave_one_out.csv` 的每折结果取舍入值。65–200 nm 的留出比值接近 1，不能抵消 350、700 nm 的偏离，更不能抵消最厚点的不稳定。六折仍来自同一旧表，并非六个独立新样品的外部验证。

再以相同六端点分别重拟合六个预设 Robin 边界，模型 `350/200 nm` 比值均为 `1.426465–1.568712`，旧端点为 `0.854167`。因此这些离散边界的训练分数变化没有修复该局部排序反例；这不是对全部可能边界或材料机制的排除。

`a=20–30 nm` 扫描若采用 `ws∝1/a`，65 nm 的相对 `P` 跨越 `0.000375–0.107626`；固定 `ws`、只改入口参考长度时仅为 `0.011193689–0.011193693`。巨大响应主要来自所选闭合规则，不是独立证实的孔径效应。固定 `a=25 nm` 的厚度斜率转折约在 `141.008 nm` 与 `7359.203 nm`；后者超出六个旧标签范围。

有限二维 PNP 中，24 格共享拟合场相对同网格零能场的盐通量比为 `5.8468×10⁻⁶`，表明这一虚拟网络条件可产生强抑制。普通 18 个空间工况在本机与导师保存的通量、电位数值一致。这些结果仅验证给定方程、边界与数值实现的相容性；不验证真实 PE 孔道、30/1 mM 虚拟边界或绝对盐通量。

对同一中性共享强场把五排网络细化至每根纤维 64 格，`J/J₀=5.8316164×10⁻⁶`，与交付 24 格差 `0.26039%`（较细网格为分母）。另一带电代表工况 `σ=−0.005 C/m²`、双面 `ws=3` 的同 `σ` 归一化比值在 24/64 格分别为 `0.43192644/0.42839372`，差 `0.82464%`。两组新格点的方程与守恒检查均通过，但差异依工况而变；有限网格之间的差额不是连续极限误差上界，也不能替代真实 PE 样品验证。逐格结果见 `复现记录_20261017_v5.md`。

六条旧时间曲线各至少有一个共同时间点低于常 `P` 有限池条件形状下界。200 nm 在 60 min 只达到 120 min 增量的 `0.10057`；简单“硬起算延迟 + 延迟后常 `P`”也不能同时穿过其 20/60/120 min 三点。原表 80/85 min 时间标签冲突，故该行不用于定量检验。缺少重复和误差条，现阶段不能区分润湿、混合、仪器响应或结构松弛。

只取共同确认的 0/60/120 min 三行，200 nm 后 60 min 与前 60 min 的电导增量比为 `8.94286`；其余五个标签在这项二分对比中为 `0.60217–1.05824`。该比值无需跨列绝对单位，但不是渗透率比，也没有误差显著性。其余曲线早期仍可偏离常 `P` 条件下界，不能据半程比值将它们判作完全符合模型。

进一步看共同确认的前三个等长 20 min 窗口，200 nm 的电导增量依次为 `0.82/0.35/0.23`，前 60 min 实际逐段减速；其后半程大比值不能表述为从起点连续加速。65、350、700、2600 nm 至少有一对早期窗口明显加速。350 nm 的 `40–60 / 20–40 min` 增量比为 `31.55556`，2600 nm 的 `20–40 / 0–20 min` 为 `1582.125`；后者首段增量仅 `0.40`（原表列单位），没有误差资料时大比值尤其脆弱。全表及条件约束见 `阶段总结/20261017_旧时间曲线内部检验.md`。

在额外假定两池封闭且充分混合、浓度差单调下降、面积/体积固定、电导与接收池盐浓度成固定比例时，若用 `J(t)=P(t)Δc(t)` 表示时间变化的有效系数，200 nm 的半程比值还给出必要约束：至少某个对应时刻的后半段 `P` 相对前半段达到 `8.94286` 倍，或者前半段对应值为零。由于旧实验条件与误差未确认，这不是 PE 固有渗透率实测增长，也不是动态机制拟合；详细推导见 `阶段总结/20261017_旧时间曲线内部检验.md`。

## 6. 讨论与结论边界

这套有效模型展示了“厚度增加可能降低双面进入能，从而与延长扩散路径竞争”的一种可复算解释。它没有证明 PE 的真实界面荷电、孔道尺度或材料微观来源。全六点训练误差、最厚点留出失败、中间边界敏感性和旧时间曲线不合必须同列于结论。当前可写“在明确假设下解释主要端点量级，同时未通过独立厚端预测和时间形状检验”，不能写“建立并验证了 PE 盐输运的唯一机制”。

### 6.1 解释能力与预测能力

参考模型用三个共享量拟合同一旧表的六个端点，训练误差较只含路径长度的基线小。这说明在所选方程与参数范围内，双面场重叠提供一种可计算的厚度形状解释。最厚点留出时 `ell` 触及预设上界且预测严重偏离，说明厚端结果依赖该端点进入训练；中间边界 `r=0.75` 的训练改善也没有解决留出失败。因此可陈述“对既有六端点的解释性拟合”，不能把曲线在训练区间内经过点附近或数值求解成功写成独立预测成功。

### 6.2 参数身份与替代解释

`ell` 来自有效场形状拟合，`a=25 nm` 来自参考闭合，`r=0` 来自边界选择。旧电导增量没有提供能把这些量分别认定为湿态孔道、界面电荷和 Debye 尺度的独立读数。图2中局部尺度响应的大部分来自预设 `ws∝1/a`；图4中早期时间曲线又违反静态常 `P` 的条件形状。润湿、混合、仪器响应或材料状态变化均尚未由旧记录区分。这里列出的是未排除的解释类别，不为任何类别补造参数或拟合曲线。

### 6.3 证据和报告准入

二维 PNP 的强抑制与守恒通过属于方程实现证据；旧端点属于条件化的相对比较证据；它们都不是绝对通量或唯一微观机制的直接证据。图1应与图4一起呈现，避免只展示训练成功；图2须保留固定 `ws` 对照，图3须明确同 `σ` 分母。正式稿还需按学校要求补充学生本人操作记录、真实文献阅读与准确引注、作者贡献及版式。当前工作稿不预填这些尚未提供的事实。
