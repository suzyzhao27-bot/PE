## S2 几何、状态与方程

H 固定 draw357 结构而变 h；S 按四锚点随 h 条件改变结构。主网6×6横向周期、n_z=max(1,ceil[h/(d_f+d_p)])，面积A=(6s)²，s=d_f+d_p，膜水相体积Σ_iV_i=εAh，ε=φ_A 为主情景。节点孔体r_i取预设截断对数正态，轴向边以p_z=0.65保留，喉半径a_e受q=0.5及面面积预算约束。节点/边、分量与预算见 `WP2/v7_network_geometry_audit.csv`；孤立成分不能假装参与贯通输运。

| 量 | 定义 | 单位/身份 |
|---|---|---|
| h,d_f,d_p,r_i,a_e,s | 膜厚、纤维直径、投影孔径、孔体半径、喉半径、格距 | m；h为盐曲线标签，d_f/d_p来自另一结构来源或条件映射 |
| V_i,A_e,A | 控制体体积、边截面、膜面积 | m³、m²、m²；模型预算 |
| K_i=exp(−βa_ref/r_i) | 节点有效盐分配 | 无量纲；非实测电荷 |
| u_i,c_i=K_iu_i | 相对活动浓度、相对局部浓度 | 无量纲；以C₀归一化 |
| M_i=V_iK_i | 节点盐容量系数 | m³ |
| g_e | 内部或外端口导通 | m³/s |
| F_ij=C₀g_ij(u_i−u_j) | 盐量流率 | mol/s，若C₀为mol/m³ |
| P=G_eff/A | 固定池稳态有效渗透率 | m/s，模型结果 |
| α=A/V_R、Q | 池几何比、电导观测尺度 | m⁻¹、μS/cm；均非直接测量 |
| β、f_e | 分配强度、ND导通比例 | 无量纲；代理参数 |

内部边 `g_e=D_b A_e exp(−βa_ref/a_e)/L_e`。外端口还串联 `1/(4D_ba_e)` 的一侧access阻力。主D_b=2D_NaD_Cl/(D_Na+D_Cl)，Na/Cl参考值分别为1.33×10⁻⁹与2.03×10⁻⁹ m²/s。池节点 K=1，`d(M_i u_i)/dt=Σ_j g_ij(u_j−u_i)`，初态左池u=1、右池及膜u=0，总盐`Σ_i M_i u_i=V_L`。对每条无向边，相加两端方程使g(u_i−u_j)和g(u_j−u_i)抵消，因此闭合盐量恒定；正质量与非负导通的图Laplacian也保持非负状态。`u_i=u_j`才是零流率平衡，`c_i=K_i u_i`可不同。对正u，闭合系统的自由能耗散为`−Σ_e g_e(u_i−u_j)(ln u_i−ln u_j)≤0`。定浓度边界需计入外界化学功。ND仅以规定τ_e改变g，不改变M。更完整推导和边界见只读 `02_静态孔网与动态扩展规格.md`。

## S3 目标、留出与数值检查

观测增量`y=κ(t)−κ(0)`，模型`ŷ=Q u_R(t)`。逐点残差`r=asinh(ŷ/[1 μS/cm])−asinh(y/[1 μS/cm])`；每膜对非零点取均方，六膜等权后开根得E。完整 B、t≤60 min训练后段、六次整膜留出及L早期/晚期条件转移都保存了真实时间、原单位值、asinh残差与状态。`WP4/all_predictions.csv`、`residuals.csv`、`cross_series_transfer.csv`及各模型原点表为数值依据。NS作为E/F单一候选由回顾性时间留出择定，不能将同一留出再称盲测。

直孔、共用求解器、正式参数T6及ND T8见 `WP2/v7_straight_chain_benchmark.csv`、`v7_two_bath_conservation.json`、`WP4/v7_N0_T6_summary.json`、`v7_NS_T6_summary.json`、`v7_ND_T6_summary.json`、`v7_ND_T8_summary.json`。C1主网384行、消融288行；C2的6对8及8对12域尺寸比较部分P差超过10%；C3圆管PNP的36工况及18容量工况均数值收敛，但最不利局部工况固定β联合偏差44.13%。PNP的零电流边界只属于局部参照，并未扩展成全离子三维孔网。
