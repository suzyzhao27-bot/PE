# 干态中性辛酸吸附：计算输入合同（冻结草案）

本文件把 2026-11-09 任务书中可以冻结的计算口径写成可执行接口。它不代替原子结构、力场或分子动力学结果。

## 已冻结的共同条件

- 探针：中性辛酸（HA），只做单一形态。
- 温度：298.15 K。
- 参照：三组使用同一稀薄理想气相活度、同一长度标准态和同一吸附层定义。
- 结构组：182、357、604；第二次双向拉伸倍率分别为 1.5、2.1、2.73。
- 结构宏观约束：见 `20261109_结构约束表.csv`。结晶度用于构模约束，XRD 相干尺寸用于域尺度约束，不能直接指定晶面暴露比例。
- 独立实现：每组 3 个真正不同的表面实现；只更换初速度不算独立结构。
- 表面观察层：统一取模型最外侧约 1 nm；需要报告有序链、边界/折叠区、无序区和可达外表面积。
- 反应坐标：分子相对局部外表面的法向距离 `z`；允许横向移动和转动。

## 目标量

对每个独立表面计算从远离表面的气相平台到表面的 `W(z)`，并在事先固定的第一吸附层边界内计算：

```text
K = (A_projection / A_real) * integral(exp(-W(z)/(R*T)) dz)
R_dry = K_604 / K_182
R_middle = K_357 / K_182
DeltaDeltaG = -R*T*ln(R)
```

若采样在局部法向坐标下已经按真实面积均匀加权，使用实际体积元，不能再次乘投影/真实面积修正。三组必须使用同一个吸附层内分子数定义、气相标准态和面积算法。

## 必须记录的轨迹量

1. 烃尾与 PE 接触数；
2. 羧基朝向和相对表面方向；
3. 分子接触的有序链束、边界/折叠区或无序区；
4. 每个区域的可达真实面积和单位真实面积贡献；
5. 伞形窗口中心、平衡/生产时长、相邻窗口重叠、时间块结果和独立结构之间的差异。

## 事前判读

- 区间整体支持 `R > 1` 才报告薄组方向证据。
- 工程解释尺度为中心约 1.5–2.3 倍；`1.84` 是随附 ζ 条件反演的参考，不能用来调结构或力场。
- 同时允许 `1` 和 `1.84` 的区间写作“当前计算分辨不开”。
- 中组若不位于两端之间，按真实结果报告，不事后重配样品标签。
- 总真实面积变大但单位真实面积 `K` 不变，不能支持表面富集机制。

## 当前阻塞接口

以下信息缺失时，不能产生 `W(z)`、`K` 或 `R_dry`：

- 三组各 3 个原子表面结构及其松弛前后坐标；
- PE 半结晶构模方案、晶体取向、周期边界和表面法向；
- PE 力场、辛酸拓扑与电荷、气相相互作用组合；
- GROMACS/伞形采样/WHAM 或 MBAR 的可执行环境；
- 表面可达面积算法和吸附层边界的实现；
- 构模种子与窗口种子。

这些字段在输入缺口表中写为 `unknown`，不以 ζ、接触角、AFM 粗糙度或表观表面能补齐。
