## 核心叙事

**科学问题。** 超薄PE膜的盐迁移抑制中，盐和中性小分子共同经历的有效传质限制，与离子额外响应分别贡献多少？这种分工如何随厚度关联的加工状态和预湿历史变化？

**已知现象。** 历史B/R系列旧盐曲线提示：名义65 nm组的盐迁移可远低于2600 nm组，乙醇预湿组可有强响应。历史B/R未认证同母膜配对，逐运行池体积、取样补液和净流也未获认证。因此这是待解释的历史现象，不能称为本批新实验重现。

**为何路长不足。** 相同通路能力时，缩短膜内路长应降低膜内阻力。归档孔口、荷电迁移和共享外阻范围下，旧W2盐速率仍要求大的有效能力差异；这一结论是所列模型族的必要界，不是对所有荷电机制的否定。逐曲线自由外阻会取消该单窗口界。

**模型。** 总传递按装置外阻、孔口阻力、膜内阻力串联；膜内迁移包含扩散、分配与带电孔的离子电迁移。组合能力 `b=εf/τ` 承载可达面积和曲折度等因素，但不能反演成实测湿孔数、润湿率或单一微观机制。中性尿素可独立约束 `b`，再用限定参数族检验盐的剩余响应。ζ/KPFM只提供辅助电性背景，不等于高盐孔内电荷密度。

**已获得的条件性认识。** 旧盐A的主条件在C1/C2下给B2600/B65的必要 `b` 比下界1358.48/1369.88；试探几何比Γ=10后为135.85/136.99。旧盐D预测主算子薄端共同响应，厚端在迁移系数±5%情景下四行覆盖比值1。B的12条速率范围诊断有10条超出固定状态G1必要范围，但早期弱信号、池状态和T12未决使其不能证明真实时间变化。A、B、D共同依赖初始NaCl浓差600 mol/m³、等体积双池、无取样补液、无净体积流的声明参照；历史逐运行条件尚未认证。±5%是敏感性情景，并非经认证的模型误差。

**真正的新增验证路径。** 同母膜B/E配对裁片、每次运行同测盐与尿素，配合外阻、质量衡算和预定的2校准/8留出盐条件，能够限制自由参数吸收现象的空间。目前这仍是已固定的实验和分析设计，不是已实现的机制结论。创新性应由未来独立探针和留出预测的实际表现决定。

## 英文稿术语锁定

| 统一术语 | 定义与使用边界 |
|---|---|
| legacy B/R; new B/E | 历史基线/乙醇预湿组与新批配对设计分开，不把R改写成E |
| parent membrane | 新批配对统计单位；裁片和时点不是独立材料重复 |
| effective transport capacity `b=εf/τ` | 组合传质能力，非实测湿孔数或润湿率 |
| `E_s`, `E_u`, `Π=E_s/E_u` | 同一窗口与同一阻力边界下的盐、尿素处理增益和相对额外响应 |
| G0/G1/G2 | 零电荷参照、归档带电孔族、小孔/短孔压力情景 |
| C1/C2; W2 | 旧电导换算情景；旧60–100 min窗口，非新实验100 min取样 |
| model envelope; 95% interval | 前者为条件参数范围，后者为未来母膜统计区间，不混称误差棒 |

## 前作定位（2026-11-02补核）

英文引言已按出版页补五条可核对引用：[Polymer 2023](https://doi.org/10.1016/j.polymer.2023.126393)支持既有UHMWPE结构、表面电势和离子排斥观察；[Advanced Materials Technologies 2023](https://doi.org/10.1002/admt.202300178)是液滴装置的面外电动学背景；[Advanced Materials 2026](https://doi.org/10.1002/adma.74297)是另一装置中的近临界PE水/电子跨膜研究。[Physical Review E 2016](https://doi.org/10.1103/PhysRevE.93.053108)提供带电毛细孔理论及适用假设；[Physical Chemistry Chemical Physics 2021](https://doi.org/10.1039/D1CP00253H)说明另一纳米孔材料中润湿/气泡会影响电输运读数。后两篇不是本PE膜的机制证据。上述前作均不能替代本研究尚未开展的同批盐/尿素H池配对验证；英文稿只用其支持明确对应的背景句。
