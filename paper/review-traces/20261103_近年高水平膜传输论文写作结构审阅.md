# 近年高水平膜传输论文的写作结构审阅

日期：2026-11-03
用途：为PE超薄膜中文初稿的叙事、结果顺序和图组职责提供写作参照。本文只借鉴公开论文的论证结构，不复制措辞，不把其他材料体系的机制移植为本项目结论。

## 1. 检索范围与筛选原则

检索集中在2023—2026年离子传输、聚合物微孔、超薄膜和限域水研究。优先选择能够直接观察“问题—机制—验证”链条的Nature、Nature Materials、Nature Communications和Advanced Materials研究论文；另保留与本PE材料及带电孔模型直接相关的支撑文献。所有纳入稿件均以出版商页面或正式DOI核对题名、期刊、年份和核心摘要信息。

## 3. 共同写作规律

1. **开篇以矛盾或瓶颈定义问题。** 高水平论文通常在摘要和引言前两段内给出一个可判定的未知，而不是先介绍全部材料制备过程。本项目最清楚的矛盾是：若其他因素不变，缩短路长应降低膜内阻力，但历史65 nm组的盐迁移可显著弱于2600 nm组。
2. **一个主图回答一个结果级问题。** 图组不是结果仓库。图1建立现象与比较设计；图2建立测量可信度；图3用双探针区分共同与离子额外响应；图4把现象转为数量界；图5检验跨条件解释力。
3. **机制主张依赖正交证据。** 结构图、单一通量或单一拟合通常不足以单独支撑机制。中性尿素、外阻和同母膜配对共同构成本项目的正交证据链。
4. **模型先约束再解释。** 先说明模型在什么条件下要求多大的有效能力差异，再讨论哪些物理过程可能形成这种差异；不从一个拟合参数直接跳到润湿率、湿孔数或电荷机制。
5. **检测限和不可识别性属于结果边界。** 低于LOQ的数据应保留区间；逐曲线自由外阻会取消单窗口能力比下界，这一数学条件必须与数量结论同时出现。
6. **摘要只保留一条发现链。** 本稿摘要的主发现是“历史盐数据在声明模型域内要求百至千倍量级的组合有效能力差异”；双探针与留出检验是把这一界转化为可证伪机制解释的设计，而不是已经完成的结果。

## 4. 对本项目的结构决策

采用“开放挑战式”引言和“核心能力＋验证包络”结果结构：

`反常厚度关联 → 单盐读数不可识别 → 串联阻力与有效能力界 → 同批双探针分解 → 预先划定的跨条件检验`

正文将理论与方法移至结果之后，使读者先看到问题、已成立的数量级发现和下一步判别逻辑；方法部分再完整交代旧数据身份、双池参照、外阻关系、模型族和统计单位。图4是当前唯一包含实质数量结果的主图，因此正文不会把图1—3和图5的占位设计写成已经获得的实验结果。

## 6. 术语锁定

| 规范术语 | 定义 | 不采用的扩张性表达 |
|---|---|---|
| 历史B/R；新批B/E | 旧基线/乙醇预湿记录与新同母膜设计分开命名 | 不把R自动改写为E |
| 组合有效传质能力 `b=εf/τ` | 可达通路与曲折度等因素的组合量 | 不称“湿孔数”“润湿率” |
| 必要下界 | 给定模型族、窗口和外阻关系下的数学约束 | 不称材料常数或实测值 |
| 条件预测 | 声明参照和参数范围内的模型输出 | 不称实验验证 |
| 相对额外响应 `Π=E_s/E_u` | 盐增益相对尿素增益的比值 | 不自动等同于电荷贡献 |
| 预先划定的留出检验 | 条件在分析前已指定，但尚无先封存后揭示记录 | 不称严格盲测 |

## 7. “发布会原则”下的Article修订（2026-11-03）

研究者明确要求正文采用原创研究Article，而不是综述、项目总结或自我审查报告。现行稿据此完成以下调整：

1. **唯一主结果上移。** 摘要、引言末段、结果4、讨论开头和结论均围绕同一个记忆点组织：历史盐迁移在声明模型域内要求百至千倍量级的组合有效能力差异。各位置分别承担“宣布、动机、证明、解释、强化”功能，不重复完整论证。
2. **文献只用于定位缺口。** 引言将外部研究压缩为一个功能段，说明水合孔门、限域能垒和受限水为何使静态几何不足；不按作者或期刊逐篇综述。讨论只用一处文献关系说明本研究的中层变量与限域传输认识如何衔接。
3. **实验按论证职责组织。** 图1建立反常现象与配对设计；图2保护膜相关信号；图3执行共同/离子额外响应分解；图4给出决定性的数量界；图5检验跨条件解释力。控制实验不再作为并列成果展开。
4. **边界下沉但不隐藏。** 共享外阻、历史双池参照、逐曲线自由外阻的取消分支和T12未决状态保留在结果必要句或方法中；项目编号、审阅过程、待办盘点和组图预览从Article正文删除。
5. **比较维度重定义。** 论文不争论PE膜是否在绝对通量或选择性上全面领先，而突出更有证据优势的贡献：把反常厚度效应变成必要数量界，并用中性共探针和留出条件提供可证伪机制分解。
