# 22号WP5质量门槛与空白实验记录模板

核对来源：`原始资料/赵珈绮/22_机制预测与实验验证方案_v1.0.0/04_考试后实验与判别.md`第4–6节、`05_复用清单与数据接口.md`第3节、`templates/experiment_record.json`、`templates/run_receipt.json`及54行固定实验矩阵。模板有32个顶层字段；54次运行均为`NOT_STARTED`。本审阅检查**数据能否承载未来判定**，没有填写或推断实测值。

| 已定质量门槛或数据 | 模板中直接字段 | 还必须关联的证据 |
|---|---|---|
| 样品独立性与B/E配对 | `parent_film_id`、`coupon_id`、`run_id`、实测`measured_h_nm`及测法 | P1–P3母膜来源和裁片对应；时间点/多裁片不增加材料重复 |
| 面积、初始体积、温度与搅拌 | `area_cm2`、`volume_initial_mL_each`、`temperature_C`、`stirrer_rpm_each` | 实际装夹和过程记录，不用方案标称值填空 |
| 预处理与支承 | `pretreatment_log`、`support_identity`、`support_preparation`、`fixture_id` | B/E/W实际时间、洗涤、支承处理；与相应控制运行相连 |
| 60/120/240 min双侧各取0.20 mL、不补液 | `sampling_events`、`volume_or_level_data_path` | 每次取样体积、前后池液位/质量和净流记录；不能只填模板默认空数组 |
| 盐与尿素原始信号 | `conductivity_data_path`、`conductivity_unit`、`urea_absorbance_data_path` | 两侧原始时间序列、吸光度、样品对应、标准曲线和换算版本 |
| 开测前尿素LOQ≤1 µM、加标回收90%–110%、LOQ以上CV≤10% | 仅`calibration_id`可引用 | 标准点、空白、基质加标、重复和本机LOQ计算的独立校准记录；模板本身无这些结果字段 |
| 电导`κ(c,u,T)`校准与低盐全批选择 | `calibration_id`、`solution_batch_id`、`salt_actual_feed_mM`、`urea_actual_feed_mM` | 两种尿素背景及温度的原始标准点、实测盐LOQ、全批一次选择记录；不可由模型示意LOQ代替 |
| 90%–110%质量回收、净流10%/30%界限 | `recovery_salt_percent`、`recovery_urea_percent`、体积路径、取样事件 | 两侧每次实测浓度、取走样品质量、净体积变化及计算过程；模板未单列净流占比 |
| 外阻/泄漏20%与尿素扰动20%筛查 | `leak_check`、`run_id` | C1/C2/C4对应原始运行及配对计算；单条膜运行不能独立证明通过 |

判定：模板可作为**运行记录索引**，不能仅凭已填顶层字段给WP5质量门槛打PASS。特别是`calibration_id`与路径必须指向可核读原始数据和计算；`run_receipt.json`是空白执行收据，`pb_calls_cumulative=0`为模板占位，不是本项目当前441次的实账。质量计算、低盐选择与任何实验结论均待真实数据。原模板和原方案不改。
