# 论文A/D参数身份核对

2026-10-31。依据25号裁剪说明、其原任务书与冻结20/23输入，审查论文计算稿里会改变A/D解释的参数身份。本表供导师侧审阅，不替代学生本人参数依据记录。

| 量 | 当前使用值或范围 | 身份与可说的结论 |
|---|---|---|
| 旧盐`λ`、`ρ=1/λ` | 20号Book2的C1/C2、W1/W2；`λ`单位`s⁻¹`，`ρ`单位`s` | 旧电导经验换算所得区间等效量；C1/C2是转换情景，不是仪器实测校准或膜内`P`。原85 min不改80 min。 |
| `h` | B/R标称65、700、2600 nm | 旧曲线分组标签；不能当每次H池运行的湿态厚度实测值。 |
| `a,τ,σ` | G1：10/25/50 nm、1/2/4、0/−2/−8/−20 mC/m²；G2另含2 nm | 声明的模型包络。干态结构/既有电性只供范围参考；湿态贯通孔半径、曲折路径和孔内真实电荷均未逐片测定。非零电荷受`τh/a≥5`长孔条件限制。 |
| `D_Na,D_Cl,D_u` | 1.33、2.03、1.38 ×10⁻⁹ m²/s | 22号规格给的25°C稀溶液工作常数；不是0.6 M NaCl下实测扩散系数。`D_s`由前两者的调和式计算。 |
| 尿素`r_u`、`H_u` | 0.18 nm工作情景，Renkin公式；原敏感性0.15/0.25 nm | 分子尺寸与长圆孔阻碍的声明情景；不是本材料的湿孔尺寸测量。 |
| 盐初始浓差、尿素初始浓度及池状态 | 旧盐条件600 mol/m³；D条件尿素10 mM、两池等体积、无取样且无净流 | 均为旧模型条件；旧Book2逐运行配液、体积、取样补液与净流未认证，不能将D浓度公式当旧实验事实或新装置靶值。 |
| `δ`、迁移系数±5% | 旧`ρ`操作性容差0/20%；±5%用于原定A及D敏感性 | 不是电导误差、置信区间或PB模型经验证误差。 |
| `K=A(1/V_D+1/V_R)`、`ξ`、`Γ` | 旧运行`K`未知；E1取`ξ=1`，E2试探`Γ=10` | 装置尺度假设；Γ不是已测上限。绝对`b`、面积和外阻不能由任意`K_ref`还原为实测值。 |
| `r_B,r_R`及尿素外阻关系 | E1/E2组内共享非负外阻；D主情景按扩散比例关联 | 模型条件，未由旧装置空白对照独立测定。逐膜/逐探针独立外阻会取消主要有限判别。 |
| 19号ζ/KPFM电性 | 现有记录另有pH、盐度和膜身份 | 不能直接代入本次600 mM旧盐曲线的孔内`σ`；不作同片B/R电荷差异证据。 |
